--- title: Einbetten description: Setzen Sie den Globus mit einer Zeile auf Ihre eigene Website – die Karte eines Kapitels, eines Ortes, eines Jahres oder einer Tour – und steuern Sie ihn von Ihrer Seite aus. ---

Der Globus läuft als iframe in jeder beliebigen Seite. Eine Zeile zeigt die Karte eines Kapitels neben der Textstelle auf Ihrer Seite; ein paar Nachrichten halten beide im Gleichschritt.

Schnellstart

<iframe
  src="{{site}}/embed/v1?ref=Acts.16&locale=de"
  title="Karte zu Apg 16"
  style="width: 100%; height: 480px; border: 0; border-radius: 12px"
  allow="fullscreen"
  loading="lazy"
></iframe>
  • Die Karte füllt den Rahmen und öffnet sich auf den Orten von Apg 16, im Jahr seiner Ereignisse.
  • Oben: das Kapitel. Wählen Sie es aus, um seine Orte in der Reihenfolge aufzulisten, in der der Text sie nennt; wählen Sie einen Ort aus, um seine Karte zu öffnen.
  • Unten: das Jahr. Wählen Sie es aus, um den Zeitregler zu öffnen.
  • Ein Link öffnet dieselbe Ansicht im vollständigen Globus in einem neuen Tab. Die Quellenangaben stehen auf der Karte selbst, wie es die Datenlizenzen verlangen.
  • Der Rahmen funktioniert bis hinunter zur Breite eines Smartphones; 480 px Höhe genügen.

Ein Kapitel oder eine Textstelle

ref nimmt einen OSIS-Verweis mit englischen Buchabkürzungen und englischer Verszählung:

Wert Zeigt
Acts.16 ein Kapitel
Gen.12-Gen.13 bis zu drei Kapitel
Acts.16.11-Acts.16.15 eine Textstelle
Ruth ein ganzes Buch

Die Karte springt in das Jahr der Textstelle: das verzeichnete Jahr ihrer Kapitel (die Kapitel von {{chapter_books}} Büchern sind datiert) oder sonst das Jahr der Tour, die sie abdeckt; ein ganzes Buch übernimmt das Jahr der Tour mit den meisten Stationen darin. Eine Textstelle ohne beides behält das aktuelle Jahr der Karte.

Parameter

Parameter Beispiel Bedeutung
ref Acts.16 Kapitel, Textstelle oder Buch (siehe oben)
year -999 Jahr in astronomischer Zählung: 1 v. Chr. ist 0, 1000 v. Chr. ist -999
place af2161c einen Ort öffnen (hier Kapernaum); die IDs sind unter Orts-IDs beschrieben
tour paul-1 eine geführte Tour starten
stop 3 zusammen mit tour: sie an dieser Station öffnen
lesson a15257a~30.a112427~30 Ihre eigene Lektion, zusammen mit tour=lesson: Orts-IDs in der Reihenfolge, jede mit dem Jahr, in dem sie gezeigt werden soll (~-585 für 586 v. Chr.: wie bei year ist 1 v. Chr. gleich 0); jede Station erhält den Vers des Ortes, der diesem Jahr am nächsten liegt, die Entfernung, die Gehzeit und das Relief. Die Schaltfläche „Zu einer Lektion hinzufügen“ auf einer Ortskarte erzeugt dieselben Links
title Paul%20in%20Galatia zusammen mit lesson: der Name der Lektion, bis zu 80 Zeichen, am Kopf ihrer Tour und ihres gedruckten Blattes
locale de Sprache, eine von {{locale_codes}}
camera 35.2,31.8,7,30,0 Längengrad, Breitengrad, Zoom, Neigung, Ausrichtung; zusammen mit place öffnet sich die Karte mit dieser Kamera und dem ausgewählten Ort, statt zu ihm zu fliegen
measure a15257a,aaf03fa zwei Orts-IDs: das Entfernungswerkzeug ist zwischen ihnen geöffnet; ein kleiner Rahmen und ui=map zeigen nur die Linie
ui map die Karte allein, für eine Seite mit eigener Suche und eigenem Ortsfeld: keine Ortskarte, keine Kapitelleiste, das Jahr eingeklappt; der Link zum Globus bleibt. Der ausgewählte Ort ist mit einem Ring markiert, und ein Klick auf die Karte abseits jedes Ortes hebt die Auswahl auf (siehe das Beispiel)
hide relief,battles auszublendende Ebenen: borders, places, relief, routes, roads, battles

Am einfachsten baut man eine Ansicht, indem man sie im vollständigen Globus einrichtet und die URL kopiert: Dieselben Parameter funktionieren nach /embed/v1.

Nachrichten

Der Globus und Ihre Seite kommunizieren über postMessage. Jede Nachricht ist ein Objekt mit type und v: 1. Der Globus sendet nur, was auf der Karte geschieht, und nie etwas, das den Leser identifiziert, daher sendet er an die übergeordnete Seite, gleich welche Herkunft sie hat (Ziel "*"); er nimmt Nachrichten nur von der Seite an, die den Rahmen enthält.

Vom Globus

Typ Nutzdaten Wann
hg:ready { view } die Karte ist gezeichnet
hg:view-changed { view } das Jahr, der Ort, die Tour oder die Kamera hat sich geändert und ist zur Ruhe gekommen (etwa 400 ms nach der letzten Änderung), gleichgültig, ob der Leser oder Ihr hg:set-view sie geändert hat. Fliegt die Karte zu einem neu ausgewählten Ort, kommt die Nachricht einmal mit dem neuen Ort und der Kamera, die die Karte verlassen hat, und dann noch einmal, wenn der Flug endet
hg:place-clicked { place } der Leser hat einen Ort auf der Karte angeklickt, auch den schon ausgewählten; die Nachricht kommt vor dem hg:view-changed, das der Klick auslöst
hg:verse-clicked { osis } der Leser hat einen Vers in einer Ortskarte angeklickt, z. B. "Acts.16.12"
hg:error { code, message } die Karte oder ihre Daten konnten nicht geladen werden: code ist "map" oder "data"

view enthält year, locale und layers und, wenn gesetzt, place, tour, stop, ref und camera. Eine view ohne place bedeutet, dass kein Ort ausgewählt ist. camera ist ein Objekt, { center: [35.2, 31.8], zoom: 7, pitch: 30, bearing: 0 }, nicht die Zeichenkette der Adresse; layers gibt jeder Ebene true oder false: { relief: false, battles: false }.

An den Globus

Typ Nutzdaten Wirkung
hg:set-view { view } das Jahr, das Kapitel (ref), den Ort, die Ebenen oder die Kamera setzen; mit tour (und stop) startet die Tour, und die übrigen Felder werden ignoriert; die Sprache ändert sich nur mit hg:set-locale. place: null hebt die Auswahl auf und beendet eine laufende Tour. Zum bereits ausgewählten Ort fliegt die Karte erneut, es sei denn, die Ansicht enthält auch camera. Eine Orts-ID, die die Karte nicht kennt, wird ignoriert
hg:set-locale { locale } die Sprache wechseln
  • Warten Sie auf hg:ready, bevor Sie etwas senden: Eine Nachricht, die gesendet wird, solange die Karte noch lädt, geht verloren.
  • Behandeln Sie hg:view-changed als den aktuellen Zustand, nicht als etwas, das der Leser getan hat: Es folgt auf Ihr eigenes hg:set-view und auf jede Bewegung der Kamera. Eine Seite, die die ganze Ansicht samt Kamera so zurückschickt, wie sie sie erhalten hat, löst weder eine Schleife noch einen Flug aus. Beantworten Sie hg:view-changed nicht mit hg:set-view und nur einem place: Ohne camera fliegt die Karte zu diesem Ort zurück, weg von der Stelle, an die der Leser sie bewegt hat.

Orts-IDs

Ein Ort der Bibel hat die ID von OpenBible: a gefolgt von sechs hexadezimalen Ziffern, etwa af2161c (Kapernaum). Die Orte der antiken Welt, die die Bibel nicht nennt (Gamla, Sepphoris, Pompeji), haben stattdessen ihre Pleiades-Nummer (die von Gamla ist 678146) oder, wenn sie keine haben, ihren Wikidata-Eintrag (der von Konstantinopel ist Q16869). Beide Arten können in view.place und hg:place-clicked vorkommen, und beide werden von hg:set-view akzeptiert; wenn Ihre Daten nur Orte von OpenBible enthalten, prüfen Sie die Form der ID, bevor Sie einen Ort nachschlagen. Von den {{openbible}} Orten von OpenBible sind {{absent}} nicht auf der Karte (weggelassen oder ganz ohne Punkt); ihre IDs werden ignoriert.

Beispiel: Die Karte folgt Ihrer Bibel-App

const globe = document.querySelector("iframe").contentWindow;
const globeOrigin = "{{site}}";

// Wenn Ihre Bibel-App ein Kapitel öffnet, es auf der Karte zeigen.
function showChapter(osis) {
  globe.postMessage({ type: "hg:set-view", v: 1, view: { ref: osis } }, globeOrigin);
}

// Wenn auf der Karte ein Vers angeklickt wird, ihn in Ihrer Bibel-App öffnen.
window.addEventListener("message", (e) => {
  if (e.source !== globe || e.origin !== globeOrigin) return;
  if (e.data?.type === "hg:verse-clicked") openVerse(e.data.osis);
});

Beispiel: Die Karte neben Ihrem eigenen Ortsfeld

<iframe src="{{site}}/embed/v1?ui=map&place=af2161c&locale=en" title="Map"></iframe>
const globe = document.querySelector("iframe").contentWindow;
const globeOrigin = "{{site}}";
let ready = false;

window.addEventListener("message", (e) => {
  if (e.source !== globe || e.origin !== globeOrigin) return;
  const m = e.data;
  if (m?.type === "hg:ready") ready = true;
  // Die Ansicht, wie sie jetzt ist: ein Ort ausgewählt oder keiner. Kommt oft: showPlace sollte
  // nichts tun, wenn dieser Ort schon angezeigt wird.
  if (m?.type === "hg:ready" || m?.type === "hg:view-changed") {
    if (m.view.place) showPlace(m.view.place);
    else hidePlace();
  }
  // Jeder Klick auf einen Ort, auch auf den schon ausgewählten: Ihr Ortsfeld wieder öffnen.
  if (m?.type === "hg:place-clicked") showPlace(m.place);
});

// Ihre Suche hat einen Ort gewählt: auswählen und hinfliegen (erneut, wenn er schon
// ausgewählt ist).
function pickPlace(id) {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: id } }, globeOrigin);
}

// Ihr Ortsfeld wurde geschlossen: die Auswahl auf der Karte aufheben.
function closeBox() {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: null } }, globeOrigin);
}
  • Der ausgewählte Ort ist mit einem Ring markiert, der wächst und verblasst, sodass das Auge ihn findet, ohne dass etwas die Karte verdeckt; bei einem Leser, der um weniger Bewegung gebeten hat, bleibt der Ring still.
  • Ein Klick auf die Karte abseits jedes Ortes hebt die Auswahl des Ortes auf; eine laufende Tour geht weiter. Ein Doppelklick (der zoomt) und ein Klick, der die sich bewegende Karte anhält, heben nichts auf. place: null von Ihrer Seite hebt die Auswahl des Ortes auf und beendet die Tour.
  • Eine Tour läuft auf der Karte (ihre Route, ihre Stationen und das Jahr) ohne ihre Tourkarte: Ihre Seite steuert sie mit hg:set-view und { tour, stop }. measure zeichnet seine Linie, wie in jedem Rahmen.
  • hg:verse-clicked wird nicht gesendet: Die Verse stehen in der Ortskarte, die dieser Modus weglässt.

Orte in jedem Text

Eine weitere Zeile verknüpft die Orte der Bibel, die Ihr eigener Text nennt (ein Artikel, eine Predigt, ein Leseplan), mit dem Globus. Zeigen Sie auf einen Namen oder tippen Sie ihn auf dem Smartphone an, und eine Karte zeigt, was der Ort ist, wo er heute liegt, wie viele Verse ihn nennen und wo er auf der Karte liegt; die Karte führt zum Globus. 

<script src="{{hgPlacesSrc}}" integrity="{{hgPlacesIntegrity}}" crossorigin="anonymous" data-scope="article" charset="utf-8" defer></script>

Die Adresse trägt eine Version, und der Integritäts-Hash legt ihren genauen Inhalt fest: Der Browser führt das Skript nur aus, wenn es genau diese Datei ist. Eine neue Version bekommt eine neue Adresse; die alten bleiben, wie sie sind.

Attribut Was es bewirkt
data-scope wo gesucht wird, als CSS-Selektor; standardmäßig die ganze Seite
data-locale die Sprache des Textes, eine der Sprachen der Website: {{locale_codes}}; standardmäßig das lang der Seite; bei jeder anderen Englisch
data-every jede Erwähnung verlinken, nicht nur die erste je Ort
data-theme light oder dark für die Karte; standardmäßig folgt sie dem System des Lesers

Verlinkt werden nur Namen, die auf einen einzigen Ort zeigen. Ein Name, den sich zwei Orte teilen (Antiochia in Syrien und in Pisidien), ein Ort und eine Person (Juda) oder ein Ort und ein gewöhnliches Wort, bleibt einfacher Text, ebenso ein Name, den die Verse der Bibel meist für etwas anderes verwenden („Kadesch“ ist dort Kadesch-Barnea, nicht das Kadesch der Datenbank). Der Name eines Ortes, der zugleich ein Vorname ist (Jordan, Saron), bleibt neben einem anderen großgeschriebenen Wort unberührt: Jordan Smith ist eine Person, nicht der Fluss. Im Russischen, Ukrainischen, Polnischen, Tschechischen, Serbischen, Ungarischen, Finnischen und Rumänischen werden Namen in ihren gebeugten Formen gefunden („в Египте“, „w Jerozolimie“, „v Jeruzalémě“), deutsche, schwedische, dänische und norwegische Namen auch im Genitiv („Jerusalems“). Links, Code, Formularfelder, Schaltflächen und Überschriften bleiben unberührt.

Das Skript hat keine Abhängigkeiten und setzt keine Cookies. Es liest eine Namensdatei vom Globus (je nach Sprache etwa {{names_kb_min}} bis {{names_kb_max}} KB über das Netz, dazu {{script_kb}} KB Skript), ohne die Adresse Ihrer Seite als Referrer, und ändert nur die Namen, die es verlinkt. Es funktioniert mit einer strengen Content Security Policy, die die Adresse des Globus in script-src und connect-src erlaubt. Für Text, den Ihre Seite später hinzufügt, rufen Sie HistoryGlobePlaces.scan(element) auf, sobald der Text gerendert ist: Das Skript teilt Textknoten, daher führen Sie es auf einer React- oder Vue-Seite für Inhalte aus, die das Framework nicht mehr neu rendert.

Stabilität

/embed/v1 ist ein Vertrag: Innerhalb von v1 werden Parameter und Nachrichten nur hinzugefügt, nie geändert oder entfernt. Eine inkompatible Änderung erscheint als /embed/v2, und v1 funktioniert weiter.
