--- title: Einbetten description: Setzen Sie den Globus mit einer Zeile auf Ihre eigene Website – die Karte eines Kapitels, eines Ortes, eines Jahres oder einer Tour – und steuern Sie ihn von Ihrer Seite aus. ---

Der Globus läuft als iframe in jeder beliebigen Seite. Eine Zeile zeigt die Karte eines Kapitels neben der Textstelle auf Ihrer Seite; ein paar Nachrichten halten beide im Gleichschritt.

Schnellstart

<iframe
  src="{{site}}/embed/v1?ref=Acts.16&locale=de"
  title="Map of Acts 16"
  style="width: 100%; height: 480px; border: 0; border-radius: 12px"
  allow="fullscreen"
  loading="lazy"
></iframe>
  • Die Karte füllt den Rahmen und öffnet sich auf den Orten von Apg 16, im Jahr seiner Ereignisse.
  • Oben: das Kapitel. Wählen Sie es aus, um seine Orte in der Reihenfolge aufzulisten, in der der Text sie nennt; wählen Sie einen Ort aus, um seine Karte zu öffnen.
  • Unten: das Jahr. Wählen Sie es aus, um den Zeitregler zu öffnen.
  • Ein Link öffnet dieselbe Ansicht im vollständigen Globus in einem neuen Tab. Die Quellenangaben stehen auf der Karte selbst, wie es die Datenlizenzen verlangen.
  • Der Rahmen funktioniert bis hinunter zur Breite eines Smartphones; 480 px Höhe genügen.

Ein Kapitel oder eine Textstelle

ref nimmt einen OSIS-Verweis mit englischen Buchabkürzungen und englischer Verszählung:

Wert Zeigt
Acts.16 ein Kapitel
Gen.12-Gen.13 bis zu drei Kapitel
Acts.16.11-Acts.16.15 eine Textstelle
Ruth ein ganzes Buch

Die Karte springt in das Jahr der Textstelle: das verzeichnete Jahr ihrer Kapitel (die Kapitel von {{chapter_books}} Büchern sind datiert) oder sonst das Jahr der Tour, die sie abdeckt; ein ganzes Buch übernimmt das Jahr der Tour mit den meisten Stationen darin. Eine Textstelle ohne beides behält das aktuelle Jahr der Karte.

Parameter

Parameter Beispiel Bedeutung
ref Acts.16 Kapitel, Textstelle oder Buch (siehe oben)
year -999 Jahr in astronomischer Zählung: 1 v. Chr. ist 0, 1000 v. Chr. ist -999
place af2161c einen Ort öffnen (hier Kapernaum); die IDs stammen von OpenBible
tour paul-1 eine geführte Tour starten
stop 3 zusammen mit tour: sie an dieser Station öffnen
lesson a15257a~30.a112427~30 Ihre eigene Lektion, zusammen mit tour=lesson: Orts-IDs in der Reihenfolge, jede mit dem Jahr, in dem sie gezeigt werden soll (~-585 für 586 v. Chr.: wie bei year ist 1 v. Chr. gleich 0); jede Station erhält den Vers des Ortes, der diesem Jahr am nächsten liegt, die Entfernung, die Gehzeit und das Relief. Die Schaltfläche „Zu einer Lektion hinzufügen“ auf einer Ortskarte erzeugt dieselben Links
title Paul%20in%20Galatia zusammen mit lesson: der Name der Lektion, bis zu 80 Zeichen, am Kopf ihrer Tour und ihres gedruckten Blattes
locale de Sprache: en, ru, uk, es, pt, de, fr, it, nl, pl oder cs
camera 35.2,31.8,7,30,0 Längengrad, Breitengrad, Zoom, Neigung, Ausrichtung
hide relief,ancient auszublendende Ebenen: borders, places, relief, routes, roads, ancient

Am einfachsten baut man eine Ansicht, indem man sie im vollständigen Globus einrichtet und die URL kopiert: Dieselben Parameter funktionieren nach /embed/v1.

Nachrichten

Der Globus und Ihre Seite kommunizieren über postMessage. Jede Nachricht ist ein Objekt mit type und v: 1. Der Globus sendet nur, was auf der Karte geschieht, und nie etwas, das den Leser identifiziert; er nimmt Nachrichten nur von der Seite an, die den Rahmen enthält.

Vom Globus

Typ Nutzdaten Wann
hg:ready { view } die Karte ist gezeichnet
hg:view-changed { view } das Jahr, der Ort, die Tour oder die Kamera hat sich geändert und ist zur Ruhe gekommen
hg:verse-clicked { osis } der Leser hat einen Vers angeklickt, z. B. "Acts.16.12"
hg:error { code, message } die Karte oder ihre Daten konnten nicht geladen werden

view enthält year, locale und layers und, wenn gesetzt, place, tour, stop, ref und camera.

An den Globus

Typ Nutzdaten Wirkung
hg:set-view { view } das Jahr, das Kapitel (ref), den Ort, die Ebenen oder die Kamera setzen; mit tour (und stop) startet die Tour, und die übrigen Felder werden ignoriert; die Sprache ändert sich nur mit hg:set-locale
hg:set-locale { locale } die Sprache wechseln

Beispiel: Die Karte folgt Ihrem Leser

const globe = document.querySelector("iframe").contentWindow;

// When your reader opens a chapter, show it on the map.
function showChapter(osis) {
  globe.postMessage({ type: "hg:set-view", v: 1, view: { ref: osis } }, "*");
}

// When a verse is clicked on the map, open it in your reader.
window.addEventListener("message", (e) => {
  if (e.source !== globe) return;
  if (e.data?.type === "hg:verse-clicked") openVerse(e.data.osis);
});

Orte in jedem Text

Eine weitere Zeile verknüpft die Orte der Bibel, die Ihr eigener Text nennt (ein Artikel, eine Predigt, ein Leseplan), mit dem Globus. Zeigen Sie auf einen Namen oder tippen Sie ihn auf dem Smartphone an, und eine Karte zeigt, was der Ort ist, wo er heute liegt, wie viele Verse ihn nennen und wo er auf der Karte liegt; die Karte führt zum Globus. 

<script src="{{site}}/hg-places.js" data-scope="article" charset="utf-8" defer></script>
Attribut Was es bewirkt
data-scope wo gesucht wird, als CSS-Selektor; standardmäßig die ganze Seite
data-locale die Sprache des Textes, eine der Sprachen der Website: cs, de, en, es, fr, it, nl, pl, pt, ru, uk; standardmäßig das lang der Seite; bei jeder anderen Englisch
data-every jede Erwähnung verlinken, nicht nur die erste je Ort
data-theme light oder dark für die Karte; standardmäßig folgt sie dem System des Lesers

Verlinkt werden nur Namen, die auf einen einzigen Ort zeigen. Ein Name, den sich zwei Orte teilen (Antiochia in Syrien und in Pisidien), ein Ort und eine Person (Juda) oder ein Ort und ein gewöhnliches Wort, bleibt einfacher Text, ebenso ein Name, den die Verse der Bibel meist für etwas anderes verwenden („Kadesch“ ist dort Kadesch-Barnea, nicht das Kadesch der Datenbank). Der Name eines Ortes, der zugleich ein Vorname ist (Jordan, Saron), bleibt neben einem anderen großgeschriebenen Wort unberührt: Jordan Smith ist eine Person, nicht der Fluss. Im Russischen, Ukrainischen, Polnischen und Tschechischen werden Namen in ihren gebeugten Formen gefunden („в Египте“, „w Jerozolimie“, „v Jeruzalémě“), deutsche Namen auch im Genitiv („Jerusalems“). Links, Code, Formularfelder, Schaltflächen und Überschriften bleiben unberührt.

Das Skript hat keine Abhängigkeiten und setzt keine Cookies. Es liest eine Namensdatei vom Globus (je nach Sprache etwa 20 bis 35 KB über das Netz, dazu 7 KB Skript), ohne die Adresse Ihrer Seite als Referrer, und ändert nur die Namen, die es verlinkt. Es funktioniert mit einer strengen Content Security Policy, die die Adresse des Globus in script-src und connect-src erlaubt. Für Text, den Ihre Seite später hinzufügt, rufen Sie HistoryGlobePlaces.scan(element) auf, sobald der Text gerendert ist: Das Skript teilt Textknoten, daher führen Sie es auf einer React- oder Vue-Seite für Inhalte aus, die das Framework nicht mehr neu rendert.

Stabilität

/embed/v1 ist ein Vertrag: Innerhalb von v1 werden Parameter und Nachrichten nur hinzugefügt, nie geändert oder entfernt. Eine inkompatible Änderung erscheint als /embed/v2, und v1 funktioniert weiter.
