Alles, was der Globus über Orte, Verse, Personen und Reisen weiß, steht Ihnen zum Aufbauen offen: über die offenen Daten und das Einbetten. Der Globus selbst, seine Artikel und sein Code sind nicht zum Kopieren da. Diese Seite sagt, wo die Grenze verläuft.

Was Sie übernehmen dürfen

Was Lizenz Wie
Die Daten: Orte mit ihren Namen in allen Sprachen, Punkte, die Verse und Kapitel, die sie nennen, Personen, Touren, Ereignisse, Schlachten, antike Autoren CC BY 4.0 {{site}}/api/v1/ – JSON-Dateien, kein Schlüssel, keine Anmeldung. Nutzen Sie sie, verändern Sie sie, verkaufen Sie, was Sie damit bauen; die Quellenangabe bleibt.
Die Karte auf Ihrer Seite frei Ein iframe: Einbetten. Die Quellenangaben stehen auf der Karte selbst.
Links und Karten für die Orte der Bibel, die Ihre eigenen Texte nennen frei Ein Skript: Orte in jedem Text.
Die Ortsartikel und die beantworteten Fragen, in allen Sprachen CC BY-NC-ND 4.0 Zitieren, verlinken und teilen Sie sie, wie sie sind, mit Quellenangabe. Verändern, übersetzen oder neu veröffentlichen Sie sie nicht, und nehmen Sie sie nicht in einen Datensatz auf.
Die Website, ihr Code und ihr Design alle Rechte vorbehalten Dass der Code auf GitHub zu lesen ist, gibt kein Recht, ihn zu nutzen. Keine Spiegel, keine Kopien des Globus, keine Website aus seinem Bundle oder seinen /data-Dateien.

Kurz gesagt: Nehmen Sie die Daten über die API und nennen Sie die Quelle; zeigen Sie die Karte über das Einbetten; klonen Sie den Globus nicht.

Wie Sie die Quellen nennen

Wo Sie die Daten zeigen, nennen Sie ihre Quellen, so wie index.json sie aufführt. Die kürzeste Form, die den Lizenzen genügt: 

Daten: History Globe von Vadym Arnaut ({{site}}), CC BY 4.0;
Orte und Verszuordnungen von OpenBible.info (CC BY 4.0); Personen von STEPBible TIPNR (CC BY 4.0).

Auf einer Seite, mit Links:

<p>Daten: <a href="{{site}}/">History Globe</a> von Vadym Arnaut,
  <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>;
  Orte von <a href="https://www.openbible.info/geo/">OpenBible.info</a>,
  Personen von <a href="https://www.stepbible.org/">STEPBible</a>.</p>

{{site}}/api/v1/index.json enthält die vollständigen Quellenangaben, und jede Antwort der API wird mit einem Link-Header gesendet, der ihre Lizenz nennt. Ein zitierter Artikel oder eine zitierte Antwort wird als „History Globe (Vadym Arnaut), CC BY-NC-ND 4.0“ angegeben, mit einem Link zu seiner Seite.

Grenzen

  • Kein Schlüssel, kein Kontingent. Die API besteht aus statischen Dateien hinter einem Cache. Laden Sie jede Datei beim Bauen oder einmal am Tag; sie ändern sich nur mit einer Veröffentlichung, und index.json nennt deren Datum.
  • Version 1 wächst nur. Felder und Dateien kommen hinzu, nichts wird umbenannt oder entfernt; ignorieren Sie ein Feld, das Sie nicht kennen. Die Beschreibung in OpenAPI 3.1 wird vor jeder Veröffentlichung gegen jede Datei geprüft.
  • /data ist nicht die API. Die Dateien unter /data/ sind das, was die Karte lädt: Ihre Form ändert sich ohne Ankündigung, und Anfragen an sie können begrenzt werden. Bauen Sie auf /api/v1/ auf.
  • Fotografien behalten ihre eigenen Lizenzen, angegeben auf jeder Ortsseite und auf der Seite Quellen.
