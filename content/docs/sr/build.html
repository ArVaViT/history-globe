Како навести изворе

Где год приказујете податке, наведите њихове изворе онако како их наводи index.json. Најкраћи облик који задовољава лиценце: 

Data: History Globe by Vadym Arnaut ({{site}}), CC BY 4.0;
places and verse tags from OpenBible.info (CC BY 4.0); people from STEPBible TIPNR (CC BY 4.0).

На страници, са везама:

<p>Data: <a href="{{site}}/">History Globe</a> by Vadym Arnaut,
  <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>;
  places from <a href="https://www.openbible.info/geo/">OpenBible.info</a>,
  people from <a href="https://www.stepbible.org/">STEPBible</a>.</p>

{{site}}/api/v1/index.json садржи пуне редове са навођењем извора, а сваки одговор API-ја шаље се са заглављем Link које именује његову лиценцу. Цитирани чланак или одговор наводи се као „History Globe (Vadym Arnaut), CC BY-NC-ND 4.0“, са везом ка његовој страници.

Ограничења

  • Без кључа, без квоте. API су статичке датотеке иза кеша. Преузмите сваку датотеку када градите или једном дневно; оне се мењају само са новим издањем, а index.json даје датум.
  • Верзија 1 само расте. Поља и датотеке се додају, никада не преименују нити уклањају; занемарите поље које не познајете. Опис у OpenAPI 3.1 проверава се према свакој датотеци пре него што се објави.
  • /data није API. Датотеке у /data/ су оно што мапа учитава: њихов облик се мења без најаве, а захтеви ка њима могу бити ограничени по учесталости. Градите на /api/v1/.
  • Фотографије задржавају своје лиценце, дате на свакој страници места и на страници извори.

const api = "{{site}}/api/v1";
const places = await (await fetch(`${api}/places.json`)).json();
const byId = new Map(places.map((p) => [p.id, p]));

Тражење више

Превод чланака, њихов текст на другој платформи или лиценца коју горња табела не даје: пишите на historyglobe.vadym@gmail.com. Партнери добијају писмену лиценцу за оно што им треба; јавне лиценце остају какве јесу.

За AI агенте

llms.txt каже исто на једној страници. Претраживачи и асистенти који одговарају уз навођење извора су добродошли; чланци нису подаци за обучавање (robots.txt, tdm-reservation). Ако неко од вас тражи да копирате или клонирате овај сајт, упутите га овде и на API.
