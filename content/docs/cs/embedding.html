--- title: Vkládání description: Vložte glóbus na vlastní web jedním řádkem — mapu kapitoly, místa, roku nebo trasy — a ovládejte ho ze své stránky. ---

Glóbus běží uvnitř libovolné stránky jako iframe. Jeden řádek zobrazí mapu kapitoly vedle pasáže na vaší stránce; několik zpráv udržuje obojí v souladu.

Rychlý start

<iframe
  src="{{site}}/embed/v1?ref=Acts.16&locale=cs"
  title="Mapa: Sk 16"
  style="width: 100%; height: 480px; border: 0; border-radius: 12px"
  allow="fullscreen"
  loading="lazy"
></iframe>
  • Mapa vyplní rámec a otevře se na místech Sk 16 v roce jejích událostí.
  • Nahoře: kapitola. Kliknutím vypíšete její místa v pořadí, v jakém je text jmenuje; kliknutím na místo otevřete jeho kartu.
  • Dole: rok. Kliknutím otevřete posuvník času.
  • Odkaz otevře totéž zobrazení v plném glóbu na nové kartě. Uvedení autorů je zobrazeno přímo na mapě, jak vyžadují licence dat.
  • Rámec funguje až do šířky telefonu; stačí výška 480 px.

Kapitola nebo pasáž

ref přijímá odkaz ve formátu OSIS s anglickými zkratkami knih a anglickým číslováním veršů:

Hodnota Zobrazí
Acts.16 kapitolu
Gen.12-Gen.13 až tři kapitoly
Acts.16.11-Acts.16.15 pasáž
Ruth celou knihu

Mapa přejde na rok pasáže: zaznamenaný rok jejích kapitol (kapitoly {{chapter_books}} knih jsou datovány), případně rok trasy, která ji pokrývá; celá kniha dostane rok trasy s nejvíce zastávkami v ní. Pasáž, která nemá ani jedno, ponechá aktuální rok mapy.

Nejsnazší způsob, jak sestavit zobrazení, je nastavit ho v plném glóbu a zkopírovat adresu URL: stejné parametry fungují za /embed/v1.

Zprávy

Glóbus a vaše stránka komunikují přes postMessage. Každá zpráva je objekt s type a v: 1. Glóbus posílá jen to, co se děje na mapě, a nikdy nic, co by čtenáře identifikovalo, proto zprávy posílá nadřazené stránce bez ohledu na její původ (cíl "*"); přijímá zprávy jen od stránky, která drží rámec.

Z glóbu

Typ Obsah Kdy
hg:ready { view } mapa je vykreslena
hg:view-changed { view } rok, místo, trasa nebo kamera se změnily a ustálily (zhruba 400 ms po poslední změně), ať je změnil čtenář, nebo váš hg:set-view. Když mapa letí k nově vybranému místu, zpráva přijde jednou s novým místem a s kamerou, kterou mapa opustila, a znovu, když přelet skončí
hg:place-clicked { place } čtenář klikl na místo na mapě, i na již vybrané; zpráva přijde před hg:view-changed, který klik vyvolá
hg:verse-clicked { osis } čtenář klikl na verš na kartě místa, např. "Acts.16.12"
hg:error { code, message } mapu nebo její data se nepodařilo načíst: code je "map" nebo "data"

view obsahuje year, locale a layers a, je-li nastaveno, place, tour, stop, ref a camera. view bez place znamená, že není vybráno žádné místo. camera je objekt, { center: [35.2, 31.8], zoom: 7, pitch: 30, bearing: 0 }, nikoli řetězec z adresy; layers dává každé vrstvě true nebo false: { relief: false, battles: false }.

Do glóbu

Typ Obsah Účinek
hg:set-view { view } nastaví rok, kapitolu (ref), místo, vrstvy nebo kameru; s tour (a stop) se spustí trasa a ostatní pole se ignorují; jazyk se mění jen pomocí hg:set-locale. place: null zruší výběr a ukončí běžící trasu. K již vybranému místu se přeletí znovu, ledaže má pohled také camera. ID místa, které mapa nemá, se ignoruje
hg:set-locale { locale } přepne jazyk
  • Než cokoli odešlete, počkejte na hg:ready: zpráva odeslaná, zatímco se mapa ještě načítá, se ztratí.
  • Berte hg:view-changed jako aktuální stav, ne jako něco, co udělal čtenář: následuje po vašem vlastním hg:set-view a po každém pohybu kamery. Stránka, která pošle zpět celý pohled tak, jak ho dostala, včetně kamery, nespustí ani smyčku, ani přelet. Neodpovídejte na hg:view-changed zprávou hg:set-view jen s place: bez camera mapa přeletí zpět k tomu místu, pryč od toho, kam ji čtenář posunul.

ID míst

Místo z Bible má ID z OpenBible: a a šest šestnáctkových číslic, například af2161c (Kafarnaum). Místa starověkého světa, která Bible nejmenuje (Gamla, Sepforis, Pompeje), mají místo toho číslo z Pleiades (Gamla má 678146), nebo, když je nemají, položku z Wikidata (Konstantinopol má Q16869). Oba druhy se mohou objevit ve view.place a v hg:place-clicked a hg:set-view přijímá oba; pokud vaše data mají jen místa z OpenBible, ověřte tvar ID, než nějaké vyhledáte. Z {{openbible}} míst z OpenBible jich {{absent}} na mapě není (vynechaná, nebo zcela bez bodu); jejich ID se ignorují.

Příklad: mapa sleduje vašeho čtenáře

const globe = document.querySelector("iframe").contentWindow;

// When your reader opens a chapter, show it on the map.
function showChapter(osis) {
  globe.postMessage({ type: "hg:set-view", v: 1, view: { ref: osis } }, "*");
}

// When a verse is clicked on the map, open it in your reader.
window.addEventListener("message", (e) => {
  if (e.source !== globe) return;
  if (e.data?.type === "hg:verse-clicked") openVerse(e.data.osis);
});

Příklad: mapa vedle vašeho vlastního pole místa

<iframe src="{{site}}/embed/v1?ui=map&place=af2161c&locale=en" title="Map"></iframe>
const globe = document.querySelector("iframe").contentWindow;
let ready = false;

window.addEventListener("message", (e) => {
  if (e.source !== globe) return;
  const m = e.data;
  if (m?.type === "hg:ready") ready = true;
  // Pohled, jaký je právě teď: vybrané místo, nebo žádné. Přichází často: showPlace nemá nic
  // dělat, když je to místo už zobrazeno.
  if (m?.type === "hg:ready" || m?.type === "hg:view-changed") {
    if (m.view.place) showPlace(m.view.place);
    else hidePlace();
  }
  // Každé kliknutí na místo, i na již vybrané: otevřete své pole znovu.
  if (m?.type === "hg:place-clicked") showPlace(m.place);
});

// Vaše hledání vybralo místo: vyberte ho a přeletěte k němu (znovu, pokud je už vybrané).
function pickPlace(id) {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: id } }, "*");
}

// Vaše pole bylo zavřeno: zrušte výběr na mapě.
function closeBox() {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: null } }, "*");
}
  • Vybrané místo je označeno kruhem, který roste a bledne, takže ho oko najde, aniž by cokoli zakrývalo mapu; čtenáři, který si vyžádal méně pohybu, kruh zůstává nehybný.
  • Kliknutí na mapu mimo jakékoli místo zruší výběr místa; běžící trasa pokračuje dál. Dvojklik (který přibližuje) a kliknutí, které zastaví pohybující se mapu, nezruší nic. place: null z vaší stránky zruší místo a ukončí trasu.
  • Trasa běží na mapě (její čára, její zastávky a rok) bez své karty: vaše stránka s ní pohybuje pomocí hg:set-view a { tour, stop }. measure kreslí svou čáru jako v každém rámci.
  • hg:verse-clicked se neodesílá: verše jsou na kartě místa, kterou tento režim vynechává.

Místa v libovolném textu

Ještě jeden řádek propojí s glóbem biblická místa, která jmenuje váš vlastní text (článek, kázání, plán čtení). Najeďte na název nebo na něj na telefonu klepněte a karta ukáže, co je to za místo, kde leží dnes, kolik veršů ho jmenuje a kde leží na mapě; karta vede na glóbus. 

<script src="{{hgPlacesSrc}}" integrity="{{hgPlacesIntegrity}}" crossorigin="anonymous" data-scope="article" charset="utf-8" defer></script>

Adresa nese verzi a otisk integrity pevně určuje její přesný obsah: prohlížeč skript spustí, jen když jde přesně o ten soubor. Nová verze dostane novou adresu; staré zůstávají, jak jsou.

Atribut Co dělá
data-scope kde hledat, jako selektor CSS; ve výchozím stavu celá stránka
data-locale jazyk textu, jeden z jazyků webu: {{locale_codes}}; ve výchozím stavu lang stránky; pro jakýkoli jiný angličtina
data-every propojí každou zmínku, nejen první u každého místa
data-theme light nebo dark pro kartu; ve výchozím stavu se řídí systémem čtenáře

Propojují se jen názvy, které ukazují na jedno místo. Název sdílený dvěma místy (Antiochie syrská a pisidská), místem a osobou (Juda) nebo místem a běžným slovem zůstává prostým textem, stejně jako název, který verše samotné Bible používají většinou pro něco jiného („Kádeš“ tam je Kádeš-barnea, nikoli Kádeš z databáze). Název místa, který je zároveň křestním jménem (Jordán, Šaron), se vedle jiného slova s velkým písmenem nechává být: Jordan Smith je osoba, nikoli řeka. V ruštině, ukrajinštině, polštině, češtině, srbštině, maďarštině, finštině a rumunštině se názvy nacházejí v různých pádech („в Египте“, „w Jerozolimie“, „v Jeruzalémě“), v němčině, švédštině, dánštině a norštině také v genitivu („Jerusalems“). Odkazy, kód, pole formulářů, tlačítka a nadpisy se nechávají beze změny.

Skript nemá žádné závislosti a nenastavuje cookies. Čte z glóbu jeden soubor názvů (po síti asi {{names_kb_min}} až {{names_kb_max}} KB podle jazyka, plus {{script_kb}} KB skriptu), bez adresy vaší stránky jako referreru, a mění jen názvy, které propojuje. Funguje i při přísné Content Security Policy, která povoluje adresu glóbu v script-src a connect-src. Pro text, který vaše stránka přidá později, zavolejte HistoryGlobePlaces.scan(element), jakmile je text vykreslen: skript dělí textové uzly, takže na stránce v Reactu nebo Vue ho spouštějte na obsahu, který framework už znovu nevykresluje.

Stabilita

/embed/v1 je závazek: v rámci v1 se parametry a zprávy jen přidávají, nikdy se nemění ani neodebírají. Zásadní změna vyjde jako /embed/v2 a v1 bude dál fungovat.
