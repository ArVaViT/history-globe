--- title: Stavějte na tom description: Co si z History Globe smíte vzít a jak — data přes API, mapu přes vkládání — a co zůstává glóbu. ---

Vše, co glóbus ví o místech, verších, lidech a cestách, můžete použít ve svých projektech — přes otevřená data a vkládání. Samotný glóbus, jeho články a jeho kód ke kopírování nejsou. Tato stránka říká, kde vede hranice.

Co si smíte vzít

Co Licence Jak
Data: místa s názvy ve všech jazycích, body, verše a kapitoly, které je jmenují, lidé, trasy, události, bitvy, antičtí autoři CC BY 4.0 {{site}}/api/v1/ — soubory JSON, bez klíče, bez registrace. Používejte je, upravujte je, prodávejte, co z nich vytvoříte; uvádějte prameny.
Mapa na vaší stránce zdarma Jeden iframe: Vkládání. Uvedení autorů je vykresleno přímo na mapě.
Odkazy a karty pro biblická místa, která jmenují vaše vlastní texty zdarma Jeden skript: Místa v libovolném textu.
Články o místech a zodpovězené otázky, ve všech jazycích CC BY-NC-ND 4.0 Citujte je, odkazujte na ně, sdílejte je tak, jak jsou, s uvedením zdroje. Neměňte je, nepřekládejte je ani je znovu nepublikujte a nevkládejte je do datové sady.
Web, jeho kód a jeho design všechna práva vyhrazena Čtení kódu na GitHubu nedává žádné právo ho použít. Žádná zrcadla, žádné kopie glóbu, žádný web postavený z jeho bundlu nebo ze souborů /data.

Krátce: berte data přes API a uvádějte zdroj; mapu zobrazujte přes vkládání; glóbus neklonujte.

Jak uvést autory

Tam, kde data zobrazujete, uveďte jejich prameny tak, jak je uvádí index.json. Nejkratší podoba, která licencím vyhoví: 

Data: History Globe, autor Vadym Arnaut ({{site}}), CC BY 4.0;
místa a značky veršů z OpenBible.info (CC BY 4.0); lidé ze STEPBible TIPNR (CC BY 4.0).

Na stránce, s odkazy:

<p>Data: <a href="{{site}}/">History Globe</a>, autor Vadym Arnaut,
  <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>;
  místa z <a href="https://www.openbible.info/geo/">OpenBible.info</a>,
  lidé ze <a href="https://www.stepbible.org/">STEPBible</a>.</p>

{{site}}/api/v1/index.json nese úplné řádky s uvedením autorů a každá odpověď API se posílá s hlavičkou Link, která jmenuje její licenci. Citovaný článek nebo odpověď se uvádí jako „History Globe (Vadym Arnaut), CC BY-NC-ND 4.0“ s odkazem na jeho stránku.

Omezení

  • Bez klíče, bez kvóty. API jsou statické soubory za cache. Každý soubor stahujte při sestavení nebo jednou denně; mění se jen s vydáním a index.json uvádí jeho datum.
  • Verze 1 jen roste. Pole a soubory se přidávají, nikdy nepřejmenovávají ani neodebírají; pole, které neznáte, ignorujte. Popis v OpenAPI 3.1 se před zveřejněním ověřuje proti každému souboru.
  • /data není API. Soubory pod /data/ jsou to, co načítá mapa: jejich podoba se mění bez upozornění a požadavky na ně mohou být omezovány. Stavějte na /api/v1/.
  • Fotografie si ponechávají vlastní licence, uvedené na stránce každého místa a na stránce pramenů.

Začněte

const api = "{{site}}/api/v1";
const places = await (await fetch(`${api}/places.json`)).json();
const byId = new Map(places.map((p) => [p.id, p]));
const acts = await (await fetch(`${api}/verses/Acts.json`)).json();
for (const id of acts["Acts.16.12"]) console.log(byId.get(id).name); // Filipy …

Soubory a jejich pole: Otevřená data. Popis pro generátory kódu a agenty: openapi.json.

Žádost o víc

Překlad článků, jejich text na jiné platformě nebo licence, kterou tabulka výše nedává: napište na historyglobe.vadym@gmail.com. Partneři dostanou písemnou licenci na to, co potřebují; veřejné licence zůstávají, jak jsou.
