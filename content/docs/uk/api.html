--- title: Відкриті дані description: Місця, вірші, що їх називають, події та екскурсії у файлах JSON, якими може користуватися будь-хто за ліцензією CC BY 4.0 — без ключа й без реєстрації. ---

Усе, що глобус знає про місця й вірші, відкрите: прості файли JSON, які можна вільно використовувати на іншому сайті чи в застосунку за ліцензією CC BY 4.0. Без ключа, без реєстрації, без обмежень, окрім звичайного кешування.

Які місця названо у вірші

По файлу на книгу Біблії: кожен вірш, що називає місце, з ідентифікаторами цих місць.

GET {{site}}/api/v1/verses/Acts.json

{ "Acts.16.11": ["a6a7150", "a68750d", "a91c509"], "Acts.16.12": ["a69e1b8", "a49e1d0"], … }

Самі місця — з назвами всіма мовами сайту, видом і точкою — є в places.json; зв’язуйте за id. Поле першої версії name_ru залишилося й збігається з names.ru. 

GET {{site}}/api/v1/places.json

[{ "id": "a49e1d0", "name": "Philippi",
   "names": { "cs": "Filipy", "de": "Philippi", "es": "Filipos", …, "ru": "Филиппы", "uk": "Філіппи" },
   "kind": "settlement", "lon": 24.28458, "lat": 41.01207, "verses": 4,
   "wikidata": "Q379652", "pleiades": "501482",
   "page": { "cs": "/cs/place/philippi/", "de": "/de/place/philippi/", …, "uk": "/uk/place/philippi/" } }, …]

Хто і де в розділі

По файлу на книгу: кожен розділ з місцями та людьми, яких він називає. Людей ідентифіковано так, як у TIPNR від STEPBible; їхні імена й перший вірш — у people.json. 

GET {{site}}/api/v1/chapters/Acts.json

{ "Acts.16": { "places": ["a6a7150", "a49e1d0", …],
               "people": ["Lydia@Act.16.14-", "Paul@Act.7.58-2Pe", "Silas@Act.15.22-1Pe", …] }, … }

Усі файли

Файл Що містить
/api/v1/index.json перелік файлів і книг, ліцензію й відомості про авторство, дату збірки
/api/v1/places.json усі місця: id, назви, вид, точку, у скількох віршах воно назване, його сторінку (для місця, яке називає якийсь вірш); wikidata і pleiades — те саме місце в цих довідниках, де воно відоме
/api/v1/verses/{Book}.json вірш → місця, які він називає, по файлу на книгу (Gen, 1Kgs, Acts…)
/api/v1/chapters/{Book}.json розділ → місця й люди, яких він називає, по файлу на книгу
/api/v1/people.json люди, яких називає Біблія: id за TIPNR, ім’я, імена іншими мовами сайту, де вони є, стать, у скількох віршах їх названо, перший із них
/api/v1/events.json події з датами, з ref там, де подію розповідає Біблія
/api/v1/battles.json битви й облоги: місце, рік, сторони та результат, з ref там, де битву розповідає Біблія
/api/v1/questions.json питання, які ставлять люди, з відповідями обома мовами, з виглядом мапи та джерелами
/api/v1/tours.json екскурсії: їхні зупинки по порядку, кожна з уривком і приміткою; by: "sea" для відрізка морем і sailed (дні та вірш), де текст каже, скільки він тривав
/api/v1/ancient.json що про місце кажуть автори поза Біблією: автор, твір, уривок, посилання на вільний текст, стислий виклад
/api/v1/openapi.json усе це в описі OpenAPI 3.1 — для генераторів коду й агентів

Домовленості

  • Посилання — OSIS з англійськими скороченнями назв книг і нумерацією King James: Gen.12.6, Acts.16.12-Acts.16.15.
  • Роки астрономічні: 1 р. до н. е. — це 0, 586 р. до н. е. — це −585.
  • Місце, яке у вихідних даних зазначене двічі під однією назвою, має "duplicate": true; місце зі спірною локалізацією — "disputed": true.
  • Файли перебудовуються з кожним випуском даних; index.json подає його дату.
  • Перша версія лише росте: поля й файли додаються, але не перейменовуються й не зникають. Незнайоме поле просто ігноруйте.
