--- title: Вбудовування description: Розмістіть глобус на власному сайті одним рядком — мапу розділу, місця, року чи екскурсії — і керуйте ним зі своєї сторінки. ---

Глобус працює всередині будь-якої сторінки як iframe. Один рядок показує мапу розділу поруч з уривком на вашій сторінці; кілька повідомлень узгоджують їх між собою.

Швидкий початок

<iframe
  src="{{site}}/embed/v1?ref=Acts.16&locale=uk"
  title="Мапа Дій 16"
  style="width: 100%; height: 480px; border: 0; border-radius: 12px"
  allow="fullscreen"
  loading="lazy"
></iframe>
  • Мапа заповнює рамку й відкривається на місцях Дій 16 у рік його подій.
  • Угорі: розділ. Виберіть його, щоб побачити список його місць у порядку, в якому їх називає текст; виберіть місце, щоб відкрити його картку.
  • Унизу: рік. Виберіть його, щоб відкрити повзунок часу.
  • Посилання відкриває той самий вигляд у повному глобусі в новій вкладці. Відомості про авторів даних показано просто на мапі, як того вимагають ліцензії.
  • Рамка працює до ширини телефона; достатньо висоти 480 px.

Розділ або уривок

ref приймає посилання OSIS з англійськими скороченнями назв книг й англійською нумерацією віршів:

Значення Показує
Acts.16 розділ
Gen.12-Gen.13 до трьох розділів
Acts.16.11-Acts.16.15 уривок
Ruth усю книгу

Мапа переходить до року уривка: до записаного року його розділів (датовано розділи {{chapter_books|книги|книг|книг}}), а якщо його немає — до року екскурсії, яка його охоплює; для цілої книги береться рік екскурсії, що має в ній найбільше зупинок. Якщо немає ні того, ні іншого, мапа лишає поточний рік.

Найпростіше створити вигляд так: налаштувати його на повному глобусі й скопіювати URL — ті самі параметри працюють після /embed/v1.

Повідомлення

Глобус і ваша сторінка спілкуються через postMessage. Кожне повідомлення — це об’єкт із type і v: 1. Глобус надсилає лише те, що відбувається на мапі, і ніколи нічого, що ідентифікує читача, тож надсилає повідомлення батьківській сторінці незалежно від її origin (ціль "*"); повідомлення він приймає лише від сторінки, яка містить рамку.

Від глобуса

Тип Вміст Коли
hg:ready { view } мапу намальовано
hg:view-changed { view } рік, місце, екскурсія чи камера змінилися й усталилися (приблизно за 400 мс після останньої зміни), чи то читач, чи ваш hg:set-view їх змінив. Коли мапа летить до щойно вибраного місця, повідомлення приходить один раз із новим місцем і камерою, яку мапа покинула, а потім ще раз, коли переліт закінчиться
hg:place-clicked { place } читач натиснув місце на мапі, зокрема вже вибране; повідомлення приходить раніше за hg:view-changed, спричинене цим натисканням
hg:verse-clicked { osis } читач натиснув вірш у картці місця, напр. "Acts.16.12"
hg:error { code, message } мапа або її дані не завантажилися: code — "map" або "data"

view містить year, locale і layers та, якщо їх задано, place, tour, stop, ref і camera. view без place означає, що жодне місце не вибране. camera — об’єкт, { center: [35.2, 31.8], zoom: 7, pitch: 30, bearing: 0 }, а не рядок з адреси; layers задає кожному шару true або false: { relief: false, battles: false }.

До глобуса

Тип Вміст Дія
hg:set-view { view } задати рік, розділ (ref), місце, шари чи камеру; з tour (і stop) екскурсія починається, а інші поля ігноруються; мова змінюється лише через hg:set-locale. place: null знімає вибір і завершує екскурсію, що триває. До вже вибраного місця мапа летить знову, хіба що вигляд містить і camera. Ідентифікатор місця, якого на мапі немає, ігнорується
hg:set-locale { locale } перемкнути мову
  • Дочекайтеся hg:ready, перш ніж щось надсилати: повідомлення, надіслане, поки мапа ще завантажується, губиться.
  • Сприймайте hg:view-changed як поточний стан, а не як дію читача: воно йде слідом за вашим hg:set-view і за кожним рухом камери. Сторінка, що надсилає назад увесь вигляд таким, яким їй його повідомили, разом із камерою, не запускає ні циклу, ні перельоту. Не відповідайте на hg:view-changed повідомленням hg:set-view лише з place: без camera мапа летить назад до цього місця, геть звідти, куди читач її пересунув.

Ідентифікатори місць

Біблійне місце має ідентифікатор OpenBible: a і шість шістнадцяткових цифр, наприклад af2161c (Капернаум). Місця стародавнього світу, яких Біблія не називає (Гамла, Сепфоріс, Помпеї), мають натомість номер Pleiades (у Гамли це 678146), а якщо його немає, то елемент Wikidata (у Константинополя це Q16869). Обидва види можуть приходити в view.place і hg:place-clicked, і обидва приймає hg:set-view; якщо у ваших даних є лише місця OpenBible, перевіряйте вигляд ідентифікатора, перш ніж шукати його. З {{openbible}} місць OpenBible {{absent}} немає на мапі (вилучені або взагалі не мають точки); їхні ідентифікатори ігноруються.

Приклад: мапа йде за вашим текстом Біблії

const globe = document.querySelector("iframe").contentWindow;
const globeOrigin = "{{site}}";

// Читач відкрив розділ — показати його на мапі.
function showChapter(osis) {
  globe.postMessage({ type: "hg:set-view", v: 1, view: { ref: osis } }, globeOrigin);
}

// На мапі натиснули вірш — відкрити його у вашому тексті Біблії.
window.addEventListener("message", (e) => {
  if (e.source !== globe || e.origin !== globeOrigin) return;
  if (e.data?.type === "hg:verse-clicked") openVerse(e.data.osis);
});

Приклад: мапа поруч із вашим вікном місця

<iframe src="{{site}}/embed/v1?ui=map&place=af2161c&locale=en" title="Map"></iframe>
const globe = document.querySelector("iframe").contentWindow;
const globeOrigin = "{{site}}";
let ready = false;

window.addEventListener("message", (e) => {
  if (e.source !== globe || e.origin !== globeOrigin) return;
  const m = e.data;
  if (m?.type === "hg:ready") ready = true;
  // Вигляд, яким він є зараз: вибране місце або жодного. Приходить часто: showPlace не має нічого
  // робити, якщо це місце вже показане.
  if (m?.type === "hg:ready" || m?.type === "hg:view-changed") {
    if (m.view.place) showPlace(m.view.place);
    else hidePlace();
  }
  // Кожне натискання на місце, і на вже вибране теж: знову відкрийте своє вікно.
  if (m?.type === "hg:place-clicked") showPlace(m.place);
});

// Ваш пошук вибрав місце: виберіть його на мапі й перелетіть до нього (знову, якщо воно вже вибране).
function pickPlace(id) {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: id } }, globeOrigin);
}

// Ваше вікно закрито: зніміть вибір на мапі.
function closeBox() {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: null } }, globeOrigin);
}
  • Вибране місце позначене кільцем, яке росте й тане, тож око знаходить його, а мапу ніщо не закриває; у читача, який просив менше руху, кільце нерухоме.
  • Натискання на мапу поза місцями знімає вибір місця; екскурсія, що йде, триває далі. Подвійне натискання (воно змінює масштаб) і натискання, що зупиняє рухому мапу, нічого не знімають. place: null із вашої сторінки знімає вибір місця й завершує екскурсію.
  • Екскурсія йде на мапі (її маршрут, зупинки й рік) без своєї картки: ваша сторінка рухає її через hg:set-view і { tour, stop }. measure малює свою лінію, як у кожній рамці.
  • hg:verse-clicked не надсилається: вірші містяться в картці місця, якої цей режим не показує.

Місця в будь-якому тексті

Ще один рядок пов’язує з глобусом біблійні місця, які називає ваш власний текст (стаття, проповідь, план читання). Наведіть курсор на назву або торкніться її на телефоні, і картка покаже, що це за місце, де воно сьогодні, у скількох віршах воно назване і де лежить на мапі; картка веде на глобус. 

<script src="{{hgPlacesSrc}}" integrity="{{hgPlacesIntegrity}}" crossorigin="anonymous" data-scope="article" charset="utf-8" defer></script>

В адресі стоїть версія, а хеш цілісності закріплює її точний вміст: браузер виконає скрипт, лише якщо це саме той файл. Нова версія отримує нову адресу; старі лишаються як є.

Атрибут Що робить
data-scope де шукати, CSS-селектор; за замовчуванням уся сторінка
data-locale мова тексту, одна з мов сайту: {{locale_codes}}; за замовчуванням lang сторінки; будь-яка інша мова замінюється англійською
data-every пов’язувати кожну згадку, а не лише першу для кожного місця
data-theme light або dark для картки; за замовчуванням — як у системі читача

Пов’язуються лише назви, що вказують на одне місце. Назва, спільна для двох місць (Антіохія — Сирійська й Пісідійська), для місця й людини (Юда) або для місця й звичайного слова, лишається простим текстом; так само лишається назва, яку самі вірші Біблії здебільшого вживають для чогось іншого («Кадес» там — це Кадес-Варні, а не Кадес із бази даних). Назва місця, що є також особовим ім’ям (Йордан, Шарон), поруч з іншим словом з великої літери не чіпається: Йордан Сміт — це людина, а не річка. У російській, українській, польській, чеській, сербській, угорській, фінській і румунській мовах назви знаходяться в різних відмінках («в Египте», «w Jerozolimie», «v Jeruzalémě»), а в німецькій, шведській, данській і норвезькій — ще й у родовому («Jerusalems»). Посилання, код, поля форм, кнопки й заголовки скрипт не чіпає.

Скрипт не має залежностей і не встановлює cookie. Він читає з глобуса один файл назв (мережею від {{names_kb_min}} до {{names_kb_max}} КБ залежно від мови, плюс {{script_kb}} КБ самого скрипта), не передаючи адреси вашої сторінки як referrer, і змінює лише ті назви, які пов’язує. Він працює за суворої політики безпеки вмісту (CSP), яка дозволяє адресу глобуса в script-src і connect-src. Для тексту, який ваша сторінка додає пізніше, викличте HistoryGlobePlaces.scan(element), коли текст уже відтворено: скрипт розділяє текстові вузли, тож на сторінці React чи Vue запускайте його на вмісті, який фреймворк більше не перемальовує.

Стабільність

/embed/v1 — це контракт: у межах v1 параметри та повідомлення лише додаються, ніколи не змінюються й не вилучаються. Зміна, несумісна з попередніми версіями, вийде як /embed/v2, а v1 і далі працюватиме.
