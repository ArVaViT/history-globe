--- title: Вбудовування description: Розмістіть глобус на власному сайті одним рядком — мапу розділу, місця, року чи екскурсії — і керуйте ним зі своєї сторінки. ---

Глобус працює всередині будь-якої сторінки як iframe. Один рядок показує мапу розділу поруч з уривком на вашій сторінці; кілька повідомлень узгоджують їх між собою.

Швидкий початок

<iframe
  src="{{site}}/embed/v1?ref=Acts.16&locale=uk"
  title="Мапа Дій 16"
  style="width: 100%; height: 480px; border: 0; border-radius: 12px"
  allow="fullscreen"
  loading="lazy"
></iframe>
  • Мапа заповнює рамку й відкривається на місцях Дій 16 у рік його подій.
  • Угорі: розділ. Виберіть його, щоб побачити список його місць у порядку, в якому їх називає текст; виберіть місце, щоб відкрити його картку.
  • Унизу: рік. Виберіть його, щоб відкрити повзунок часу.
  • Посилання відкриває той самий вигляд у повному глобусі в новій вкладці. Відомості про авторів даних показано просто на мапі, як того вимагають ліцензії.
  • Рамка працює до ширини телефона; достатньо висоти 480 px.

Розділ або уривок

ref приймає посилання OSIS з англійськими скороченнями назв книг й англійською нумерацією віршів:

Значення Показує
Acts.16 розділ
Gen.12-Gen.13 до трьох розділів
Acts.16.11-Acts.16.15 уривок
Ruth усю книгу

Мапа переходить до року уривка: до записаного року його розділів (датовано розділи {{chapter_books|книги|книг|книг}}), а якщо його немає — до року екскурсії, яка його охоплює; для цілої книги береться рік екскурсії, що має в ній найбільше зупинок. Якщо немає ні того, ні іншого, мапа лишає поточний рік.

Найпростіше створити вигляд так: налаштувати його на повному глобусі й скопіювати URL — ті самі параметри працюють після /embed/v1.

Повідомлення

Глобус і ваша сторінка спілкуються через postMessage. Кожне повідомлення — це об’єкт із type і v: 1. Глобус надсилає лише те, що відбувається на мапі, і ніколи нічого, що ідентифікує читача; повідомлення він приймає лише від сторінки, яка містить рамку.

Від глобуса

Тип Вміст Коли
hg:ready { view } мапу намальовано
hg:view-changed { view } рік, місце, екскурсія чи камера змінилися й заспокоїлися
hg:verse-clicked { osis } читач натиснув вірш, напр. "Acts.16.12"
hg:error { code, message } мапа або її дані не завантажилися

view містить year, locale і layers та, якщо їх задано, place, tour, stop, ref і camera.

До глобуса

Тип Вміст Дія
hg:set-view { view } задати рік, розділ (ref), місце, шари чи камеру; з tour (і stop) екскурсія починається, а інші поля ігноруються; мова змінюється лише через hg:set-locale
hg:set-locale { locale } перемкнути мову

Приклад: мапа йде за вашим читачем

const globe = document.querySelector("iframe").contentWindow;

// Читач відкрив розділ — показати його на мапі.
function showChapter(osis) {
  globe.postMessage({ type: "hg:set-view", v: 1, view: { ref: osis } }, "*");
}

// На мапі натиснули вірш — відкрити його у вашому тексті Біблії.
window.addEventListener("message", (e) => {
  if (e.source !== globe) return;
  if (e.data?.type === "hg:verse-clicked") openVerse(e.data.osis);
});

Місця в будь-якому тексті

Ще один рядок пов’язує з глобусом біблійні місця, які називає ваш власний текст (стаття, проповідь, план читання). Наведіть курсор на назву або торкніться її на телефоні, і картка покаже, що це за місце, де воно сьогодні, у скількох віршах воно назване і де лежить на мапі; картка веде на глобус. 

<script src="{{site}}/hg-places.js" data-scope="article" charset="utf-8" defer></script>
Атрибут Що робить
data-scope де шукати, CSS-селектор; за замовчуванням уся сторінка
data-locale en або ru: мова тексту; за замовчуванням — lang сторінки
data-every пов’язувати кожну згадку, а не лише першу для кожного місця
data-theme light або dark для картки; за замовчуванням — як у системі читача

Пов’язуються лише назви, що вказують на одне місце. Назва, спільна для двох місць (Антіохія — Сирійська й Пісідійська), для місця й людини (Юда) або для місця й звичайного слова, лишається простим текстом; так само лишається назва, яку самі вірші Біблії здебільшого вживають для чогось іншого («Кадес» там — це Кадес-Варні, а не Кадес із бази даних). Назва місця, що є також особовим ім’ям (Йордан, Шарон), поруч з іншим словом з великої літери не чіпається: Йордан Сміт — це людина, а не річка. Російські назви знаходяться в усіх відмінках: «в Египте», «из Антиохии Писидийской». Посилання, код, поля форм, кнопки й заголовки скрипт не чіпає.

Скрипт не має залежностей і не встановлює cookie. Він читає з глобуса один файл назв (мережею близько 25 КБ для англійської й 35 КБ для російської, плюс 7 КБ самого скрипта), не передаючи адреси вашої сторінки як referrer, і змінює лише ті назви, які пов’язує. Він працює за суворої політики безпеки вмісту (CSP), яка дозволяє адресу глобуса в script-src і connect-src. Для тексту, який ваша сторінка додає пізніше, викличте HistoryGlobePlaces.scan(element), коли текст уже відтворено: скрипт розділяє текстові вузли, тож на сторінці React чи Vue запускайте його на вмісті, який фреймворк більше не перемальовує.

Стабільність

/embed/v1 — це контракт: у межах v1 параметри та повідомлення лише додаються, ніколи не змінюються й не вилучаються. Зміна, несумісна з попередніми версіями, вийде як /embed/v2, а v1 і далі працюватиме.
