--- title: Будуйте на ньому description: Що можна брати в History Globe і як — дані через API, мапу через вбудовування — і що залишається власністю глобуса. ---

Усе, що глобус знає про місця, вірші, людей і подорожі, можна брати й будувати на цьому своє — через відкриті дані та вбудовування. Сам глобус, його статті та код копіювати не можна. Ця сторінка — про те, де проходить межа.

Що можна брати

Що Ліцензія Як
Дані: місця з назвами всіма мовами, точки, вірші й розділи, де їх названо, люди, екскурсії, події, битви, античні автори CC BY 4.0 {{site}}/api/v1/ — JSON-файли, без ключа і реєстрації. Використовуйте, змінюйте, продавайте те, що на них побудували; зберігайте зазначення джерела.
Мапа на вашій сторінці безкоштовно Один iframe: Вбудовування. Джерела зазначено на самій мапі.
Посилання і картки для біблійних місць, названих у ваших текстах безкоштовно Один скрипт: Місця в будь-якому тексті.
Статті про місця та відповіді на запитання, всіма мовами CC BY-NC-ND 4.0 Цитуйте, посилайтеся, діліться ними як є, із зазначенням джерела. Не змінюйте, не перекладайте, не публікуйте наново і не додавайте до наборів даних.

Коротко: дані беріть через API і зазначайте джерело; мапу показуйте через вбудовування; глобус не клонуйте.

Як зазначити джерело

Там, де ви показуєте дані, назвіть їхні джерела так, як перелічує index.json. Найкоротша форма, достатня для ліцензій: 

Дані: History Globe, Vadym Arnaut ({{site}}), CC BY 4.0;
місця і прив'язки віршів — OpenBible.info (CC BY 4.0); люди — STEPBible TIPNR (CC BY 4.0).

На сторінці, з посиланнями:

<p>Дані: <a href="{{site}}/">History Globe</a>, Vadym Arnaut,
  <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>;
  місця — <a href="https://www.openbible.info/geo/">OpenBible.info</a>,
  люди — <a href="https://www.stepbible.org/">STEPBible</a>.</p>

Повні рядки зазначення джерел — у {{site}}/api/v1/index.json, і кожна відповідь API надходить із заголовком Link, що називає її ліцензію. Процитовану статтю чи відповідь підписують «History Globe (Vadym Arnaut), CC BY-NC-ND 4.0» із посиланням на її сторінку.

Обмеження

  • Без ключа і без квоти. API — це статичні файли за кешем. Забирайте кожен файл під час збирання або раз на день: вони змінюються лише з випуском, а index.json дає його дату.
  • Версія 1 лише росте. Поля і файли додаються, але не перейменовуються і не вилучаються; незнайоме поле просто пропускайте. Опис в OpenAPI 3.1 звіряється з кожним файлом перед публікацією.
  • /data — не API. Файли в /data/ завантажує сама мапа: їхня форма змінюється без попередження, а запити до них можуть обмежуватися за частотою. Будуйте на /api/v1/.
  • Фотографії залишаються під своїми ліцензіями, зазначеними на сторінці кожного місця і на сторінці джерел.

З чого почати

const api = "{{site}}/api/v1";
const places = await (await fetch(`${api}/places.json`)).json();
const byId = new Map(places.map((p) => [p.id, p]));
const acts = await (await fetch(`${api}/verses/Acts.json`)).json();
for (const id of acts["Acts.16.12"]) console.log(byId.get(id).name); // Philippi …

Файли та їхні поля: Відкриті дані. Опис для генераторів коду та агентів: openapi.json.

Якщо потрібно більше

Переклад статей, їхній текст на іншій платформі або ліцензія, якої немає в таблиці вище, — пишіть на historyglobe.vadym@gmail.com. Партнери отримують письмову ліцензію на те, що їм потрібно; публічні ліцензії залишаються як є.
