--- title: Upottaminen description: Tuo maapallo omalle sivustollesi yhdellä rivillä — luvun, paikan, vuoden tai kierroksen kartta — ja ohjaa sitä omalta sivultasi. ---

Maapallo toimii millä tahansa sivulla iframe-kehyksessä. Yksi rivi näyttää luvun kartan sivusi raamatunkohdan vieressä; muutama viesti pitää ne tahdissa keskenään.

Pikaopas

<iframe
  src="{{site}}/embed/v1?ref=Acts.16&locale=fi"
  title="Kartta: Apt 16"
  style="width: 100%; height: 480px; border: 0; border-radius: 12px"
  allow="fullscreen"
  loading="lazy"
></iframe>
  • Kartta täyttää kehyksen ja avautuu Apostolien tekojen luvun 16 paikkoihin sen tapahtumien vuonna.
  • Ylhäällä: luku. Valitse se, niin sen paikat luetellaan siinä järjestyksessä, jossa teksti ne mainitsee; valitse paikka avataksesi sen kortin.
  • Alhaalla: vuosi. Valitse se avataksesi aikasäätimen.
  • Linkki avaa saman näkymän koko maapallolla uudessa välilehdessä. Lähdetiedot näytetään itse kartalla, kuten datan lisenssit edellyttävät.
  • Kehys toimii puhelimen leveyteen asti; 480 px:n korkeus riittää.

Luku tai raamatunkohta

ref ottaa OSIS-viittauksen, jossa käytetään englanninkielisiä kirjojen lyhenteitä ja englanninkielistä jakeiden numerointia:

Arvo Näyttää
Acts.16 luvun
Gen.12-Gen.13 enintään kolme lukua
Acts.16.11-Acts.16.15 raamatunkohdan
Ruth koko kirjan

Kartta siirtyy raamatunkohdan vuoteen: sen lukujen kirjattuun vuoteen ({{chapter_books}} kirjan luvut on ajoitettu) tai muuten sen kierroksen vuoteen, joka kattaa kohdan; koko kirja saa sen kierroksen vuoden, jolla on eniten pysäkkejä kirjassa. Jos kohdalla ei ole kumpaakaan, kartta pysyy nykyisessä vuodessaan.

Helpoin tapa koota näkymä on asettaa se koko maapallolla ja kopioida URL-osoite: samat parametrit toimivat osoitteen /embed/v1 perässä.

Viestit

Maapallo ja sivusi viestivät postMessage-rajapinnan kautta. Jokainen viesti on objekti, jossa on type ja v: 1. Maapallo lähettää vain sen, mitä kartalla tapahtuu, eikä koskaan mitään, mikä tunnistaisi lukijan, joten se lähettää viestit emosivulle riippumatta sen alkuperästä (kohde "*"); se hyväksyy viestejä vain sivulta, jolla kehys on.

Maapallolta

Tyyppi Sisältö Milloin
hg:ready { view } kartta on piirretty
hg:view-changed { view } vuosi, paikka, kierros tai kamera on muuttunut ja asettunut (noin 400 ms viimeisen muutoksen jälkeen), oli muuttaja lukija tai oma hg:set-view-viestisi. Kun kartta lentää vasta valittuun paikkaan, viesti tulee kerran, ja siinä on uusi paikka ja kamera, jonka kartta jätti, ja sitten uudelleen lennon päätyttyä
hg:place-clicked { place } lukija napsautti paikkaa kartalla, myös jo valittua paikkaa; se tulee ennen sitä hg:view-changed-viestiä, jonka napsautus aiheuttaa
hg:verse-clicked { osis } lukija napsautti jaetta paikan kortissa, esim. "Acts.16.12"
hg:error { code, message } karttaa tai sen dataa ei voitu ladata: code on "map" tai "data"

view sisältää kentät year, locale ja layers ja, kun ne on asetettu, place, tour, stop, ref ja camera. view, jossa ei ole kenttää place, tarkoittaa, että mitään paikkaa ei ole valittu. camera on objekti, { center: [35.2, 31.8], zoom: 7, pitch: 30, bearing: 0 }, ei osoitteen merkkijono; layers antaa jokaiselle tasolle arvon true tai false: { relief: false, battles: false }.

Maapallolle

Tyyppi Sisältö Vaikutus
hg:set-view { view } asettaa vuoden, luvun (ref), paikan, kerrokset tai kameran; kun mukana on tour (ja stop), kierros alkaa ja muut kentät ohitetaan; kieli vaihtuu vain viestillä hg:set-locale. place: null poistaa valinnan ja päättää käynnissä olevan kierroksen. Jo valittuun paikkaan lennetään uudelleen, ellei näkymässä ole myös camera. Paikan tunniste, jota kartalla ei ole, ohitetaan
hg:set-locale { locale } vaihtaa kielen
  • Odota viestiä hg:ready, ennen kuin lähetät mitään: viesti, joka lähetetään kartan vielä latautuessa, katoaa.
  • Käsittele viestiä hg:view-changed nykytilana, ei lukijan tekemänä asiana: se seuraa omaa hg:set-view-viestiäsi ja jokaista kameran liikettä. Sivu, joka lähettää koko näkymän takaisin sellaisena kuin sai sen, kamera mukaan lukien, ei aloita silmukkaa eikä lentoa. Älä vastaa viestiin hg:view-changed viestillä hg:set-view, jossa on pelkkä place: ilman kenttää camera kartta lentää takaisin siihen paikkaan, pois sieltä, minne lukija sen siirsi.

Paikkatunnisteet

Raamatun paikalla on OpenBiblen tunniste: a ja kuusi heksadesimaalinumeroa, esimerkiksi af2161c (Kapernaum). Muinaisen maailman paikoilla, joita Raamattu ei mainitse (Gamla, Sepphoris, Pompeji), on sen sijaan Pleiades-numero (Gamla on 678146) tai, jos sitä ei ole, Wikidata-kohde (Konstantinopoli on Q16869). Molempia lajeja voi tulla kenttään view.place ja viestiin hg:place-clicked, ja molemmat hyväksytään viestissä hg:set-view; jos datassasi on vain OpenBiblen paikkoja, testaa muoto, ennen kuin haet paikkaa. OpenBiblen {{openbible}} paikasta {{absent}} ei ole kartalla (ne on jätetty pois, tai niillä ei ole pistettä lainkaan); niiden tunnisteet ohitetaan.

Esimerkki: kartta seuraa raamattusovellustasi

const globe = document.querySelector("iframe").contentWindow;
const globeOrigin = "{{site}}";

// Kun raamattusovelluksesi avaa luvun, näytä se kartalla.
function showChapter(osis) {
  globe.postMessage({ type: "hg:set-view", v: 1, view: { ref: osis } }, globeOrigin);
}

// Kun kartalla napsautetaan jaetta, avaa se raamattusovelluksessasi.
window.addEventListener("message", (e) => {
  if (e.source !== globe || e.origin !== globeOrigin) return;
  if (e.data?.type === "hg:verse-clicked") openVerse(e.data.osis);
});

Esimerkki: kartta oman paikkaruutusi vieressä

<iframe src="{{site}}/embed/v1?ui=map&place=af2161c&locale=en" title="Map"></iframe>
const globe = document.querySelector("iframe").contentWindow;
const globeOrigin = "{{site}}";
let ready = false;

window.addEventListener("message", (e) => {
  if (e.source !== globe || e.origin !== globeOrigin) return;
  const m = e.data;
  if (m?.type === "hg:ready") ready = true;
  // Näkymä sellaisena kuin se on nyt: paikka valittuna tai ei. Tulee usein: showPlace ei saa
  // tehdä mitään, jos paikka on jo näkyvissä.
  if (m?.type === "hg:ready" || m?.type === "hg:view-changed") {
    if (m.view.place) showPlace(m.view.place);
    else hidePlace();
  }
  // Jokainen paikan napsautus, myös jo valitun: avaa laatikkosi uudelleen.
  if (m?.type === "hg:place-clicked") showPlace(m.place);
});

// Hakusi valitsi paikan: valitse se ja lennä sinne (uudelleen, jos se on jo valittu).
function pickPlace(id) {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: id } }, globeOrigin);
}

// Laatikkosi suljettiin: poista valinta kartalta.
function closeBox() {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: null } }, globeOrigin);
}
  • Valittu paikka merkitään renkaalla, joka kasvaa ja häipyy, jotta silmä löytää sen ilman että mikään peittää karttaa; lukijalle, joka on pyytänyt vähemmän liikettä, rengas pysyy paikallaan.
  • Napsautus kartalla kohtaan, jossa ei ole paikkaa, poistaa paikan valinnan; käynnissä oleva kierros jatkuu. Kaksoisnapsautus (joka zoomaa) ja napsautus, joka pysäyttää liikkuvan kartan, eivät poista mitään. place: null sivultasi poistaa paikan ja päättää kierroksen.
  • Kierros kulkee kartalla (reitti, pysäkit ja vuosi) ilman korttiaan: sivusi ohjaa sitä viestillä hg:set-view ja kentillä { tour, stop }. measure piirtää viivansa, kuten jokaisessa kehyksessä.
  • Viestiä hg:verse-clicked ei lähetetä: jakeet ovat paikan kortissa, jonka tämä tila jättää pois.

Paikat missä tahansa tekstissä

Vielä yksi rivi linkittää maapalloon ne Raamatun paikat, jotka oma tekstisi mainitsee (artikkeli, saarna, lukusuunnitelma). Osoita nimeä tai napauta sitä puhelimessa, niin kortti näyttää, mikä paikka on, missä se on nykyään, kuinka monessa jakeessa se mainitaan ja missä se sijaitsee kartalla; kortista pääsee maapallolle. 

<script src="{{hgPlacesSrc}}" integrity="{{hgPlacesIntegrity}}" crossorigin="anonymous" data-scope="article" charset="utf-8" defer></script>

Osoitteessa on versio, ja eheystiiviste lukitsee sen tarkan sisällön: selain suorittaa skriptin vain, jos se on juuri tuo tiedosto. Uusi versio saa uuden osoitteen; vanhat pysyvät ennallaan.

Määrite Mitä se tekee
data-scope mistä etsitään, CSS-valitsimena; oletuksena koko sivu
data-locale tekstin kieli, jokin sivuston kielistä: {{locale_codes}}; oletuksena sivun lang; mikä tahansa muu kieli palaa englantiin
data-every linkittää jokaisen maininnan, ei vain kunkin paikan ensimmäistä
data-theme kortin light tai dark; oletuksena se seuraa lukijan järjestelmää

Vain nimet, jotka viittaavat yhteen paikkaan, linkitetään. Nimi, joka on kahden paikan yhteinen (Syyrian ja Pisidian Antiokia), paikan ja henkilön yhteinen (Juuda) tai paikan ja tavallisen sanan yhteinen, jää tavalliseksi tekstiksi, samoin nimi, jota Raamatun omat jakeet käyttävät enimmäkseen jostakin muusta (”Kades” on niissä Kades-Barnea, ei tietokannan Kades). Paikan nimi, joka on myös etunimi (Jordan, Sharon), jätetään rauhaan toisen isolla alkukirjaimella kirjoitetun sanan vieressä: Jordan Smith on henkilö, ei joki. Venäjässä, ukrainassa, puolassa, tšekissä, serbiassa, unkarissa, suomessa ja romaniassa nimet löydetään taivutetuissa muodoissaan (”в Египте”, ”w Jerozolimie”, ”v Jeruzalémě”), ja saksan, ruotsin, tanskan ja norjan nimet myös genetiivissä (”Jerusalems”). Linkit, koodi, lomakekentät, painikkeet ja otsikot jätetään rauhaan.

Skriptillä ei ole riippuvuuksia, eikä se aseta evästeitä. Se lukee maapallolta yhden nimitiedoston (verkon yli noin {{names_kb_min}}–{{names_kb_max}} kt kielestä riippuen sekä {{script_kb}} kt skriptiä) lähettämättä sivusi osoitetta viittaajana, ja muuttaa vain linkittämänsä nimet. Se toimii tiukan Content Security Policyn alla, joka sallii maapallon osoitteen kohdissa script-src ja connect-src. Tekstille, jonka sivusi lisää myöhemmin, kutsu HistoryGlobePlaces.scan(element), kun teksti on piirretty: skripti jakaa tekstisolmuja, joten React- tai Vue-sivulla aja se sisältöön, jota sovelluskehys ei enää piirrä uudelleen.

Vakaus

/embed/v1 on sopimus: v1:n sisällä parametreja ja viestejä vain lisätään, niitä ei koskaan muuteta eikä poisteta. Rikkova muutos julkaistaan osoitteessa /embed/v2, ja v1 toimii edelleen.
