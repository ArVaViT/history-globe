--- title: Upottaminen description: Tuo maapallo omalle sivustollesi yhdellä rivillä — luvun, paikan, vuoden tai kierroksen kartta — ja ohjaa sitä omalta sivultasi. ---

Maapallo toimii millä tahansa sivulla iframe-kehyksessä. Yksi rivi näyttää luvun kartan sivusi raamatunkohdan vieressä; muutama viesti pitää ne tahdissa keskenään.

Pikaopas

<iframe
  src="{{site}}/embed/v1?ref=Acts.16&locale=fi"
  title="Kartta: Apt 16"
  style="width: 100%; height: 480px; border: 0; border-radius: 12px"
  allow="fullscreen"
  loading="lazy"
></iframe>
  • Kartta täyttää kehyksen ja avautuu Apostolien tekojen luvun 16 paikkoihin sen tapahtumien vuonna.
  • Ylhäällä: luku. Valitse se, niin sen paikat luetellaan siinä järjestyksessä, jossa teksti ne mainitsee; valitse paikka avataksesi sen kortin.
  • Alhaalla: vuosi. Valitse se avataksesi aikasäätimen.
  • Linkki avaa saman näkymän koko maapallolla uudessa välilehdessä. Lähdetiedot näytetään itse kartalla, kuten datan lisenssit edellyttävät.
  • Kehys toimii puhelimen leveyteen asti; 480 px:n korkeus riittää.

Luku tai raamatunkohta

ref ottaa OSIS-viittauksen, jossa käytetään englanninkielisiä kirjojen lyhenteitä ja englanninkielistä jakeiden numerointia:

Arvo Näyttää
Acts.16 luvun
Gen.12-Gen.13 enintään kolme lukua
Acts.16.11-Acts.16.15 raamatunkohdan
Ruth koko kirjan

Kartta siirtyy raamatunkohdan vuoteen: sen lukujen kirjattuun vuoteen ({{chapter_books}} kirjan luvut on ajoitettu) tai muuten sen kierroksen vuoteen, joka kattaa kohdan; koko kirja saa sen kierroksen vuoden, jolla on eniten pysäkkejä kirjassa. Jos kohdalla ei ole kumpaakaan, kartta pysyy nykyisessä vuodessaan.

Paikan kortin painike ”Lisää oppituntiin” tekee samanlaiset linkit

Helpoin tapa koota näkymä on asettaa se koko maapallolla ja kopioida URL-osoite: samat parametrit toimivat osoitteen /embed/v1 perässä.

Viestit

Maapallo ja sivusi viestivät postMessage-rajapinnan kautta. Jokainen viesti on objekti, jossa on type ja v: 1. Maapallo lähettää vain sen, mitä kartalla tapahtuu, eikä koskaan mitään, mikä tunnistaisi lukijan; se hyväksyy viestejä vain sivulta, jolla kehys on.

Maapallolta

Tyyppi Sisältö Milloin
hg:ready { view } kartta on piirretty
hg:view-changed { view } vuosi, paikka, kierros tai kamera on muuttunut ja asettunut
hg:verse-clicked { osis } lukija napsautti jaetta, esim. "Acts.16.12"
hg:error { code, message } karttaa tai sen dataa ei voitu ladata

view sisältää kentät year, locale ja layers ja, kun ne on asetettu, place, tour, stop, ref ja camera.

Maapallolle

Tyyppi Sisältö Vaikutus
hg:set-view { view } asettaa vuoden, luvun (ref), paikan, kerrokset tai kameran; kun mukana on tour (ja stop), kierros alkaa ja muut kentät ohitetaan; kieli vaihtuu vain viestillä hg:set-locale
hg:set-locale { locale } vaihtaa kielen

Esimerkki: kartta seuraa lukijaasi

const globe = document.querySelector("iframe").contentWindow;

// Kun lukijasi avaa luvun, näytä se kartalla.
function showChapter(osis) {
  globe.postMessage({ type: "hg:set-view", v: 1, view: { ref: osis } }, "*");
}

// Kun kartalla napsautetaan jaetta, avaa se lukijassasi.
window.addEventListener("message", (e) => {
  if (e.source !== globe) return;
  if (e.data?.type === "hg:verse-clicked") openVerse(e.data.osis);
});

Paikat missä tahansa tekstissä

Vielä yksi rivi linkittää maapalloon ne Raamatun paikat, jotka oma tekstisi mainitsee (artikkeli, saarna, lukusuunnitelma). Osoita nimeä tai napauta sitä puhelimessa, niin kortti näyttää, mikä paikka on, missä se on nykyään, kuinka monessa jakeessa se mainitaan ja missä se sijaitsee kartalla; kortista pääsee maapallolle. 

<script src="{{hgPlacesSrc}}" integrity="{{hgPlacesIntegrity}}" crossorigin="anonymous" data-scope="article" charset="utf-8" defer></script>

Osoitteessa on versio, ja eheystiiviste lukitsee sen tarkan sisällön: selain suorittaa skriptin vain, jos se on juuri tuo tiedosto. Uusi versio saa uuden osoitteen; vanhat pysyvät ennallaan.

Määrite Mitä se tekee
data-scope mistä etsitään, CSS-valitsimena; oletuksena koko sivu
data-locale tekstin kieli, jokin sivuston kielistä: cs, de, en, es, fi, fr, it, nl, pl, pt, ru, uk; oletuksena sivun lang; mikä tahansa muu kieli palaa englantiin
data-every linkittää jokaisen maininnan, ei vain kunkin paikan ensimmäistä
data-theme kortin light tai dark; oletuksena se seuraa lukijan järjestelmää

Vain nimet, jotka viittaavat yhteen paikkaan, linkitetään. Nimi, joka on kahden paikan yhteinen (Syyrian ja Pisidian Antiokia), paikan ja henkilön yhteinen (Juuda) tai paikan ja tavallisen sanan yhteinen, jää tavalliseksi tekstiksi, samoin nimi, jota Raamatun omat jakeet käyttävät enimmäkseen jostakin muusta (”Kades” on niissä Kades-Barnea, ei tietokannan Kades). Paikan nimi, joka on myös etunimi (Jordan, Sharon), jätetään rauhaan toisen isolla alkukirjaimella kirjoitetun sanan vieressä: Jordan Smith on henkilö, ei joki. Venäjässä, ukrainassa, puolassa ja tšekissä nimet löydetään taivutetuissa muodoissaan (”в Египте”, ”w Jerozolimie”, ”v Jeruzalémě”), ja saksan nimet myös genetiivissä (”Jerusalems”). Linkit, koodi, lomakekentät, painikkeet ja otsikot jätetään rauhaan.

Skriptillä ei ole riippuvuuksia, eikä se aseta evästeitä. Se lukee maapallolta yhden nimitiedoston (verkon yli noin 20–35 kt kielestä riippuen sekä 7 kt skriptiä) lähettämättä sivusi osoitetta viittaajana, ja muuttaa vain linkittämänsä nimet. Se toimii tiukan Content Security Policyn alla, joka sallii maapallon osoitteen kohdissa script-src ja connect-src. Tekstille, jonka sivusi lisää myöhemmin, kutsu HistoryGlobePlaces.scan(element), kun teksti on piirretty: skripti jakaa tekstisolmuja, joten React- tai Vue-sivulla aja se sisältöön, jota sovelluskehys ei enää piirrä uudelleen.

Vakaus

/embed/v1 on sopimus: v1:n sisällä parametreja ja viestejä vain lisätään, niitä ei koskaan muuteta eikä poisteta. Rikkova muutos julkaistaan osoitteessa /embed/v2, ja v1 toimii edelleen.
