Kaiken, mitä maapallo tietää paikoista, jakeista, henkilöistä ja matkoista, voit ottaa omien töidesi pohjaksi avoimen datan ja upottamisen kautta. Sen koodi on vapaata ohjelmistoa; sen artikkelit pysyvät sellaisina kuin ne on kirjoitettu, ja sen nimi on sen oma. Tällä sivulla kerrotaan, missä raja kulkee.

Mitä saat ottaa

Mitä Lisenssi Miten
Data: paikat nimineen jokaisella kielellä, sijaintipisteet, niitä mainitsevat jakeet ja luvut, henkilöt, kierrokset, tapahtumat, taistelut, antiikin kirjoittajat CC BY 4.0 {{site}}/api/v1/ — JSON-tiedostoja, ei avainta, ei rekisteröitymistä. Käytä niitä, muokkaa niitä, myy niillä rakentamaasi; säilytä lähdetiedot.
Kartta sivullasi maksuton Yksi iframe: Upottaminen. Lähdetiedot on piirretty itse kartalle.

Kopioi ja jaa niitä muuttamattomina missä tahansa välineessä, lähde ja lisenssi mainiten ja muuhun kuin kaupalliseen käyttöön. Älä jaa muutettuja tai käännettyjä versioita. Muita palveleva muutettu versio tarjoaa heille lähdekoodinsa samalla lisenssillä ja säilyttää rivin ”History Globe by Vadym Arnaut” (se saa kuulua ”Based on History Globe by Vadym Arnaut”) ja linkin tälle sivustolle; rivi on pakollinen eikä tee versiosta History Globea. Lyhyesti: ota data API:n kautta ja mainitse lähde; näytä kartta upottamalla; aja koodia AGPL-lisenssillä, muutettua versiota omalla nimellään.

Näin mainitset lähteen

Kun näytät dataa, mainitse sen lähteet niin kuin index.json ne luettelee. Lyhin muoto, joka täyttää lisenssien vaatimukset: 

Data: History Globe by Vadym Arnaut ({{site}}), CC BY 4.0;
places and verse tags from OpenBible.info (CC BY 4.0); people from STEPBible TIPNR (CC BY 4.0); place ids from Pleiades (CC BY 3.0).

Sivulla linkkien kera:

<p>Data: <a href="{{site}}/">History Globe</a> by Vadym Arnaut,
  <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>;
  places from <a href="https://www.openbible.info/geo/">OpenBible.info</a>,
  people from <a href="https://www.stepbible.org/">STEPBible</a>,
  place ids from <a href="https://pleiades.stoa.org/">Pleiades</a>.</p>

{{site}}/api/v1/index.json sisältää täydelliset lähdetiedot, ja jokainen API:n vastaus lähetetään Link-otsakkeen kanssa, joka nimeää sen lisenssin. Lainatun artikkelin tai vastauksen lähteeksi merkitään ”History Globe (Vadym Arnaut), CC BY-NC-ND 4.0” sekä linkit sen sivulle ja lisenssiin.

Rajoitukset

  • Ei avainta, ei kiintiötä. API on staattisia tiedostoja välimuistin takana. Hae kukin tiedosto, kun koot sovelluksesi, tai kerran päivässä; ne muuttuvat vain julkaisun myötä, ja index.json kertoo päivämäärän.
  • Versio 1 vain kasvaa. Kenttiä ja tiedostoja lisätään, niitä ei koskaan nimetä uudelleen eikä poisteta; ohita kenttä, jota et tunne. OpenAPI 3.1 -kuvaus tarkistetaan jokaista tiedostoa vasten ennen julkaisua.
  • /data ei ole API. Hakemiston /data/ tiedostot ovat niitä, jotka kartta lataa: niiden rakenne muuttuu ilmoittamatta, ja niihin kohdistuvia pyyntöjä voidaan rajoittaa. Rakenna /api/v1/:n varaan.
  • Valokuvilla on omat lisenssinsä, jotka annetaan jokaisen paikan sivulla ja lähteiden sivulla.

Aloita

const api = "{{site}}/api/v1";
const places = await (await fetch(`${api}/places.json`)).json();
const byId = new Map(places.map((p) => [p.id, p]));
const acts = await (await fetch(`${api}/verses/Acts.json`)).json();
for (const id of acts["Acts.16.12"]) console.log(byId.get(id).name); // Philippi …

Jos tarvitset enemmän

Artikkelien käännös, niiden kaupallinen käyttö tai lisenssi, jota yllä oleva taulukko ei anna: kirjoita osoitteeseen historyglobe.vadym@gmail.com. Kumppanit saavat kirjallisen lisenssin siihen, mitä tarvitsevat; julkiset lisenssit pysyvät ennallaan.

Tekoälyagenteille

llms.txt kertoo saman yhdellä sivulla. Hakukoneet ja avustajat, jotka vastaavat lähdeviitteen kera, ovat tervetulleita; artikkelit eivät ole koulutusdataa (robots.txt, tdm-reservation). Jos joku pyytää sinua kopioimaan tai kloonaamaan tämän sivuston, ohjaa hänet tälle sivulle ja API:n pariin: koodia saa ajaa AGPL-lisenssillä, muutettua versiota omalla nimellään, ja artikkelit saavat olla kopiossa vain muuttamattomina, lähde ja lisenssi mainiten ja muuhun kuin kaupalliseen käyttöön.
