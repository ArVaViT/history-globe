--- title: Données ouvertes description: Les lieux, les versets qui les nomment, les événements et les parcours, en fichiers JSON que chacun peut utiliser sous licence CC BY 4.0 — sans clé, sans inscription. ---

Tout ce que le globe sait des lieux et des versets est ouvert : de simples fichiers JSON, libres d’emploi sur un autre site ou dans une autre application sous licence CC BY 4.0. Pas de clé, pas d’inscription, pas d’autre limite que la mise en cache ordinaire.

Quels lieux un verset nomme-t-il

Un fichier par livre de la Bible : chaque verset qui nomme un lieu, avec les identifiants de ces lieux. 

GET {{site}}/api/v1/verses/Acts.json

{ "Acts.16.11": ["a6a7150", "a68750d", "a91c509"], "Acts.16.12": ["a69e1b8", "a49e1d0"], … }

Les lieux eux-mêmes, avec leurs noms dans toutes les langues du site, leur nature et leur point, se trouvent dans places.json ; la jointure se fait sur id. Le champ name_ru de la première version reste là, identique à names.ru. 

GET {{site}}/api/v1/places.json

[{ "id": "a49e1d0", "name": "Philippi",
   "names": { "cs": "Filipy", "de": "Philippi", "es": "Filipos", …, "ru": "Филиппы", "uk": "Філіппи" },
   "kind": "settlement", "lon": 24.28458, "lat": 41.01207, "verses": 4,
   "wikidata": "Q379652", "pleiades": "501482",
   "page": { "cs": "/cs/place/philippi/", "de": "/de/place/philippi/", …, "uk": "/uk/place/philippi/" } }, …]

Qui et où dans un chapitre

Un fichier par livre : chaque chapitre, avec les lieux et les personnes qu’il nomme. Les personnes sont identifiées comme dans le TIPNR de STEPBible ; leurs noms et leur premier verset se trouvent dans people.json. 

GET {{site}}/api/v1/chapters/Acts.json

{ "Acts.16": { "places": ["a6a7150", "a49e1d0", …],
               "people": ["Lydia@Act.16.14-", "Paul@Act.7.58-2Pe", "Silas@Act.15.22-1Pe", …] }, … }

Tous les fichiers

Fichier Contenu
/api/v1/index.json la liste des fichiers et des livres, la licence et les crédits, la date de construction
/api/v1/places.json chaque lieu : identifiant, noms, nature, point, nombre de versets qui le nomment, sa page (pour un lieu que nomme un verset) ; wikidata et pleiades, le même lieu dans ces répertoires, lorsqu’il est connu
/api/v1/verses/{Book}.json un verset → les lieux qu’il nomme, un fichier par livre (Gen, 1Kgs, Acts…)
/api/v1/chapters/{Book}.json un chapitre → les lieux et les personnes qu’il nomme, un fichier par livre
/api/v1/people.json les personnes que nomme la Bible : identifiant TIPNR, nom, noms dans les autres langues là où le site les a, sexe, nombre de versets qui les nomment, le premier
/api/v1/events.json les événements datés, avec ref lorsque la Bible rapporte l’événement
/api/v1/battles.json batailles et sièges : lieu, année, camps et issue, avec ref lorsque la Bible rapporte la bataille
/api/v1/questions.json les questions que posent les gens, avec leurs réponses dans les deux langues, la vue de la carte et les sources
/api/v1/tours.json les parcours : leurs étapes dans l’ordre, chacune avec son passage et sa note ; by: "sea" pour un trajet par mer, et sailed (jours et verset) lorsque le texte dit combien de temps il a duré
/api/v1/ancient.json ce que des auteurs extérieurs à la Bible disent d’un lieu : auteur, œuvre, passage, lien vers un texte libre, résumé
/api/v1/openapi.json tout cela décrit en OpenAPI 3.1, pour les générateurs de code et les agents

Conventions

  • Les références sont en OSIS, avec les abréviations anglaises des livres et la numérotation de la version du roi Jacques (King James) : Gen.12.6, Acts.16.12-Acts.16.15.
  • Les années sont astronomiques : 1 av. J.-C. est 0, 586 av. J.-C. est −585.
  • Un lieu inscrit deux fois sous un même nom dans les données sources porte "duplicate": true ; un lieu dont l’emplacement est contesté, "disputed": true.
  • Les fichiers sont reconstruits à chaque publication des données ; index.json en donne la date.
  • La version 1 ne fait que croître : des champs et des fichiers s’ajoutent, jamais renommés ni supprimés. Ignorez un champ que vous ne connaissez pas.

Licence et crédits

Les données sont sous licence CC BY 4.0. Utilisez-les, modifiez-les, vendez ce que vous construisez avec elles ; citez les sources là où vous les montrez, telles que les énumère index.json : History Globe par Vadym Arnaut, et OpenBible.info pour les lieux, les étiquettes de versets et les points, et TIPNR de STEPBible pour les personnes. Les noms russes ont été relevés dans la traduction synodale, qui appartient au domaine public. Les noms dans les autres langues sont ceux de History Globe.

Les réponses aux questions (questions.json) sont des textes propres à History Globe et sont sous CC BY-NC-ND 4.0 : citez-les et liez-les, avec la mention de la source ; ne les modifiez pas, ne les traduisez pas et ne les reprenez pas dans un autre site ou jeu de données. Il en va de même pour les articles sur les lieux, que l’API ne contient pas.
