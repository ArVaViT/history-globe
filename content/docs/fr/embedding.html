--- title: Intégration description: Placez le globe sur votre propre site en une ligne — la carte d’un chapitre, d’un lieu, d’une année ou d’un parcours — et pilotez-le depuis votre page. ---

Le globe fonctionne dans n’importe quelle page sous forme d’iframe. Une ligne affiche la carte d’un chapitre à côté du passage de votre page ; quelques messages les tiennent en phase.

Démarrage rapide

<iframe
  src="{{site}}/embed/v1?ref=Acts.16&locale=fr"
  title="Carte d’Actes 16"
  style="width: 100%; height: 480px; border: 0; border-radius: 12px"
  allow="fullscreen"
  loading="lazy"
></iframe>
  • La carte remplit le cadre et s’ouvre sur les lieux d’Actes 16, à l’année de ses événements.
  • En haut : le chapitre. Sélectionnez-le pour lister ses lieux dans l’ordre où le texte les nomme ; sélectionnez un lieu pour ouvrir sa fiche.
  • En bas : l’année. Sélectionnez-la pour ouvrir le curseur du temps.
  • Un lien ouvre la même vue dans le globe complet, dans un nouvel onglet. Les crédits sont affichés sur la carte elle-même, comme l’exigent les licences des données.
  • Le cadre fonctionne jusqu’à la largeur d’un téléphone ; une hauteur de 480 px suffit.

Un chapitre ou un passage

ref accepte une référence OSIS, avec les abréviations anglaises des livres et la numérotation anglaise des versets :

Valeur Affiche
Acts.16 un chapitre
Gen.12-Gen.13 jusqu’à trois chapitres
Acts.16.11-Acts.16.15 un passage
Ruth un livre entier

La carte se place sur l’année du passage : l’année consignée de ses chapitres (les chapitres de {{chapter_books}} livres sont datés), ou à défaut l’année du parcours qui le couvre ; un livre entier prend l’année du parcours qui y compte le plus d’étapes. Un passage sans l’un ni l’autre garde l’année en cours de la carte.

Paramètres

Paramètre Exemple Signification
ref Acts.16 chapitre, passage ou livre (voir ci-dessus)
year -999 année, en numérotation astronomique : 1 av. J.-C. est 0, 1000 av. J.-C. est -999
place af2161c ouvre un lieu (ici, Capernaüm) ; les identifiants sont ceux d’OpenBible
tour paul-1 lance un parcours guidé
stop 3 avec tour : l’ouvre à cette étape
lesson a15257a~30.a112427~30 votre propre leçon, avec tour=lesson : les identifiants de lieux dans l’ordre, chacun avec l’année où l’afficher (~-585 pour 586 av. J.-C. : comme pour year, 1 av. J.-C. est 0) ; chaque étape reçoit le verset du lieu le plus proche de cette année, la distance, le temps à pied et le relief. Le bouton « Ajouter à une leçon » d’une fiche de lieu construit les mêmes liens
title Paul%20en%20Galatie avec lesson : le nom de la leçon, jusqu’à 80 caractères, en tête de son parcours et de sa feuille imprimée
locale fr langue : en, ru, uk, es, pt, de ou fr
camera 35.2,31.8,7,30,0 longitude, latitude, zoom, inclinaison, orientation
hide relief,ancient couches à désactiver : borders, places, relief, routes, roads, ancient

Le plus simple pour construire une vue est de la régler sur le globe complet et de copier l’URL : les mêmes paramètres fonctionnent après /embed/v1.

Messages

Le globe et votre page communiquent par postMessage. Chaque message est un objet avec type et v: 1. Le globe n’envoie que ce qui se passe sur la carte, jamais rien qui identifie le lecteur ; il n’accepte de messages que de la page qui contient le cadre.

Du globe

Type Contenu Quand
hg:ready { view } la carte est dessinée
hg:view-changed { view } l’année, le lieu, le parcours ou la caméra a changé et s’est stabilisé
hg:verse-clicked { osis } le lecteur a cliqué sur un verset, par exemple "Acts.16.12"
hg:error { code, message } la carte ou ses données n’ont pas pu se charger

view contient year, locale et layers et, s’ils sont définis, place, tour, stop, ref et camera.

Vers le globe

Type Contenu Effet
hg:set-view { view } règle l’année, le chapitre (ref), le lieu, les couches ou la caméra ; avec tour (et stop), le parcours démarre et les autres champs sont ignorés ; la langue ne change qu’avec hg:set-locale
hg:set-locale { locale } change la langue

Exemple : la carte suit votre lecteur

const globe = document.querySelector("iframe").contentWindow;

// Quand votre lecteur ouvre un chapitre, l’afficher sur la carte.
function showChapter(osis) {
  globe.postMessage({ type: "hg:set-view", v: 1, view: { ref: osis } }, "*");
}

// Quand on clique sur un verset de la carte, l’ouvrir dans votre lecteur.
window.addEventListener("message", (e) => {
  if (e.source !== globe) return;
  if (e.data?.type === "hg:verse-clicked") openVerse(e.data.osis);
});

Les lieux dans n’importe quel texte

Une ligne de plus relie au globe les lieux bibliques que nomme votre propre texte (un article, un sermon, un plan de lecture). Pointez un nom, ou touchez-le sur un téléphone : une fiche montre ce qu’est le lieu, où il se trouve aujourd’hui, combien de versets le nomment et où il se situe sur la carte ; la fiche conduit au globe. 

<script src="{{site}}/hg-places.js" data-scope="article" charset="utf-8" defer></script>
Attribut Ce qu’il fait
data-scope où chercher, sous forme de sélecteur CSS ; toute la page par défaut
data-locale en ou ru : la langue du texte ; par défaut, le lang de la page
data-every relie chaque mention, et pas seulement la première de chaque lieu
data-theme light ou dark pour la fiche ; par défaut, elle suit le système du lecteur

Seuls les noms qui désignent un seul lieu sont reliés. Un nom partagé par deux lieux (Antioche, de Syrie et de Pisidie), par un lieu et un personnage (Juda) ou par un lieu et un mot ordinaire reste du texte simple ; il en va de même d’un nom que les versets de la Bible emploient surtout pour autre chose (« Kadesh » y désigne Kadesh-Barnéa, non le Kadesh de la base de données). Le nom d’un lieu qui est aussi un prénom (Jordan, Sharon) est laissé de côté à côté d’un autre mot à majuscule : Jordan Smith est une personne, non le fleuve. Les noms russes sont repérés dans tous leurs cas : « в Египте », « из Антиохии Писидийской ». Les liens, le code, les champs de formulaire, les boutons et les titres sont laissés tels quels.

Le script n’a aucune dépendance et ne dépose aucun cookie. Il lit sur le globe un fichier de noms (environ 25 Ko en anglais et 35 Ko en russe sur le réseau, plus 7 Ko de script), sans transmettre l’adresse de votre page comme référent, et ne modifie que les noms qu’il relie. Il fonctionne sous une Content Security Policy stricte qui autorise l’adresse du globe dans script-src et connect-src. Pour le texte que votre page ajoute plus tard, appelez HistoryGlobePlaces.scan(element) une fois le texte affiché : le script découpe les nœuds de texte ; dans une page React ou Vue, lancez-le donc sur un contenu que le framework ne réaffiche plus.

Stabilité

/embed/v1 est un contrat : dans la v1, les paramètres et les messages ne font que s’ajouter, jamais être modifiés ni supprimés. Un changement incompatible sortira sous /embed/v2, et la v1 continuera de fonctionner.
