Tout ce que le globe sait des lieux, des versets, des personnes et des voyages est à vous pour construire dessus, par les données ouvertes et l’intégration. Le globe lui-même, ses articles et son code ne sont pas à copier. Cette page dit où passe la ligne.

Comment créditer

Là où vous montrez les données, citez leurs sources telles que les énumère index.json. La forme la plus courte qui satisfait aux licences : 

Données : History Globe par Vadym Arnaut ({{site}}), CC BY 4.0 ;
lieux et étiquettes de versets d’OpenBible.info (CC BY 4.0) ; personnes de STEPBible TIPNR (CC BY 4.0).

Dans une page, avec des liens :

<p>Données : <a href="{{site}}/">History Globe</a> par Vadym Arnaut,
  <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a> ;
  lieux d’<a href="https://www.openbible.info/geo/">OpenBible.info</a>,
  personnes de <a href="https://www.stepbible.org/">STEPBible</a>.</p>

{{site}}/api/v1/index.json porte les lignes de crédit complètes, et chaque réponse de l’API est envoyée avec un en-tête Link qui nomme sa licence. Un article ou une réponse cités sont crédités « History Globe (Vadym Arnaut), CC BY-NC-ND 4.0 », avec un lien vers leur page.

Limites

  • Pas de clé, pas de quota. L’API est faite de fichiers statiques derrière un cache. Récupérez chaque fichier à la construction ou une fois par jour ; ils ne changent qu’à une publication, et index.json en donne la date.
  • La version 1 ne fait que croître. Des champs et des fichiers s’ajoutent, jamais renommés ni supprimés ; ignorez un champ que vous ne connaissez pas. La description en OpenAPI 3.1 est vérifiée contre chaque fichier avant publication.
  • /data n’est pas l’API. Les fichiers sous /data/ sont ceux que la carte charge : leur forme change sans préavis, et les requêtes vers eux peuvent être limitées. Construisez sur /api/v1/.
  • Les photographies gardent leurs propres licences, indiquées sur chaque page de lieu et sur la page des sources.

Pour commencer

const api = "{{site}}/api/v1";
const places = await (await fetch(`${api}/places.json`)).json();
const byId = new Map(places.map((p) => [p.id, p]));
const acts = await (await fetch(`${api}/verses/Acts.json`)).json();
for (const id of acts["Acts.16.12"]) console.log(byId.get(id).name); // Philippi …

Les fichiers et leurs champs : Données ouvertes. La description pour les générateurs de code et les agents : openapi.json.
