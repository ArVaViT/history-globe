--- title: Bukas na datos description: Ang mga lugar, ang mga talatang bumabanggit sa mga ito, ang mga pangyayari at ang mga paglalakbay bilang mga JSON file na magagamit ng sinuman sa ilalim ng CC BY 4.0 — walang key, walang pag-sign up. ---

Bukas ang lahat ng alam ng globo tungkol sa mga lugar at talata: mga payak na JSON file, malayang gamitin sa ibang site o app sa ilalim ng CC BY 4.0. Walang key, walang pag-sign up, walang limitasyon maliban sa karaniwang caching.

Aling mga lugar ang binabanggit ng isang talata

Isang file bawat aklat ng Biblia: bawat talatang bumabanggit ng lugar, kasama ang mga id ng mga lugar na iyon. 

GET {{site}}/api/v1/verses/Acts.json

{ "Acts.16.11": ["a6a7150", "a68750d", "a91c509"], "Acts.16.12": ["a69e1b8", "a49e1d0"], … }

Ang mga lugar mismo, kasama ang kanilang mga pangalan sa bawat wika ng site, uri at punto, ay nasa places.json; i-join sa id. Naroon pa rin ang name_ru ng unang bersiyon, kapareho ng names.ru. 

GET {{site}}/api/v1/places.json

[{ "id": "a49e1d0", "name": "Philippi",
   "names": { "cs": "Filipy", "de": "Philippi", "es": "Filipos", …, "ru": "Филиппы", "uk": "Філіппи" },
   "kind": "settlement", "lon": 24.28458, "lat": 41.01207, "verses": 4,
   "wikidata": "Q379652", "pleiades": "501482",
   "page": { "cs": "/cs/place/philippi/", "de": "/de/place/philippi/", …, "uk": "/uk/place/philippi/" } }, …]

Sino at saan sa isang kabanata

Isang file bawat aklat: bawat kabanata, kasama ang mga lugar at mga taong binabanggit nito. Kinikilala ang mga tao gaya sa TIPNR ng STEPBible; nasa people.json ang kanilang mga pangalan at unang talata. 

GET {{site}}/api/v1/chapters/Acts.json

{ "Acts.16": { "places": ["a6a7150", "a49e1d0", …],
               "people": ["Lydia@Act.16.14-", "Paul@Act.7.58-2Pe", "Silas@Act.15.22-1Pe", …] }, … }

Lahat ng mga file

File Ano ang laman nito
/api/v1/index.json ang listahan ng mga file at aklat, ang lisensya at ang mga kredito, ang petsa ng build
/api/v1/places.json bawat lugar: id, mga pangalan, uri, punto, ilang talata ang bumabanggit dito, ang pahina nito (para sa lugar na binabanggit ng ilang talata); wikidata at pleiades, ang parehong lugar sa mga gazetteer na iyon, kung kilala
/api/v1/verses/{Book}.json isang talata → ang mga lugar na binabanggit nito, isang file bawat aklat (Gen, 1Kgs, Acts…)
/api/v1/chapters/{Book}.json isang kabanata → ang mga lugar at mga taong binabanggit nito, isang file bawat aklat
/api/v1/people.json ang mga taong binabanggit ng Biblia: TIPNR id, pangalan, mga pangalan sa ibang wika kung mayroon ang site, kasarian, ilang talata ang bumabanggit sa kanila, ang una
/api/v1/events.json ang mga pangyayaring may petsa, kasama ang ref kung isinasalaysay ng Biblia ang pangyayari
/api/v1/battles.json mga labanan at pagkubkob: lugar, taon, mga panig at kinalabasan, kasama ang ref kung isinasalaysay ng Biblia ang labanan
/api/v1/questions.json mga tanong na itinatanong ng mga tao, sinagot sa dalawang wika, kasama ang tanawin ng mapa at ang mga sanggunian
/api/v1/tours.json ang mga paglalakbay: ang kanilang mga hintuan ayon sa pagkakasunod, bawat isa ay may sipi at tala; by: "sea" para sa bahaging sinakyan sa dagat, at sailed (mga araw at talata) kung sinasabi ng teksto kung gaano katagal
/api/v1/ancient.json ang sinasabi ng mga manunulat sa labas ng Biblia tungkol sa isang lugar: may-akda, akda, sipi, link sa isang libreng teksto, buod
/api/v1/openapi.json lahat ng ito ay inilarawan sa OpenAPI 3.1, para sa mga code generator at ahente

Mga kumbensiyon

  • Ang mga reperensiya ay OSIS na may mga pinaikling pangalan ng aklat sa Ingles at pagnunumero ng King James: Gen.12.6, Acts.16.12-Acts.16.15.
  • Astronomikal ang mga taon: ang 1 BK ay 0, ang 586 BK ay −585.
  • Ang lugar na dalawang beses nakalista sa ilalim ng iisang pangalan sa pinagmulang datos ay may "duplicate": true; ang lugar na pinagtatalunan ang pook, "disputed": true.
  • Muling binubuo ang mga file sa bawat release ng datos; ibinibigay ng index.json ang petsa nito.
  • Lumalago lamang ang bersiyon 1: idinaragdag ang mga field at file, hindi kailanman pinapalitan ng pangalan o inaalis. Huwag pansinin ang field na hindi mo kilala.

Lisensya at kredito

Nasa ilalim ng CC BY 4.0 ang datos. Gamitin ito, baguhin ito, ibenta ang binuo mo gamit ito; pangalanan ang mga sanggunian kung saan mo ito ipinapakita, ayon sa paglilista ng index.json: History Globe ni Vadym Arnaut, at OpenBible.info para sa mga lugar, mga tag ng talata at mga punto, at TIPNR ng STEPBible para sa mga tao. Ang mga pangalang Ruso ay binasa mula sa saling Sinodal, na nasa pampublikong dominyo. Ang mga pangalan sa ibang wika ay sariling gawa ng History Globe.

Ang mga sagot sa mga tanong (questions.json) ay sariling mga teksto ng History Globe at nasa ilalim ng CC BY-NC-ND 4.0: sipiin at i-link ang mga ito, kasama ang kredito; huwag baguhin, isalin o ilagay sa ibang site o dataset. Ganoon din ang mga artikulo ng lugar, na hindi dala ng API.
