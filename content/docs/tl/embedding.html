--- title: Pag-embed description: Ilagay ang globo sa sarili mong site sa isang linya — ang mapa ng isang kabanata, lugar, taon o paglalakbay — at kontrolin ito mula sa iyong pahina. ---

Tumatakbo ang globo sa loob ng anumang pahina bilang isang iframe. Isang linya ang nagpapakita ng mapa ng isang kabanata sa tabi ng sipi sa iyong pahina; ilang mensahe ang nagpapanatili ng pagkakasabay ng dalawa.

Mabilis na simula

<iframe
  src="{{site}}/embed/v1?ref=Acts.16&locale=en"
  title="Map of Acts 16"
  style="width: 100%; height: 480px; border: 0; border-radius: 12px"
  allow="fullscreen"
  loading="lazy"
></iframe>
  • Pinupuno ng mapa ang frame at bumubukas sa mga lugar ng Gawa 16, sa taon ng mga pangyayari nito.
  • Itaas: ang kabanata. Piliin ito para ilista ang mga lugar nito ayon sa pagkakasunod na binabanggit ng teksto; pumili ng lugar para buksan ang card nito.
  • Ibaba: ang taon. Piliin ito para buksan ang slider ng panahon.
  • Binubuksan ng isang link ang parehong tanawin sa buong globo sa bagong tab. Ipinapakita ang mga kredito sa mismong mapa, ayon sa hinihingi ng mga lisensya ng datos.
  • Gumagana ang frame hanggang sa lapad ng isang telepono; sapat na ang taas na 480 px.

Isang kabanata o isang sipi

Tumatanggap ang ref ng reperensiyang OSIS na may mga pinaikling pangalan ng aklat sa Ingles at bilang ng talata sa Ingles:

Halaga Ipinapakita
Acts.16 isang kabanata
Gen.12-Gen.13 hanggang tatlong kabanata
Acts.16.11-Acts.16.15 isang sipi
Ruth isang buong aklat

Lumilipat ang mapa sa taon ng sipi: ang naitalang taon ng mga kabanata nito (may petsa ang mga kabanata ng {{chapter_books}} aklat), o kung wala, ang taon ng paglalakbay na sumasaklaw dito; ang isang buong aklat ay kinukuha ang taon ng paglalakbay na may pinakamaraming hintuan dito. Ang sipi na walang alinman sa dalawa ay pinananatili ang kasalukuyang taon ng mapa.

Mga parameter

Parameter Halimbawa Kahulugan
ref Acts.16 kabanata, sipi o aklat (sa itaas)
year -999 taon, sa astronomikal na pagbibilang: ang 1 BK ay 0, ang 1000 BK ay -999
place af2161c magbukas ng lugar (dito, ang Capernaum); mula sa OpenBible ang mga ID
tour paul-1 simulan ang isang paglalakbay na may gabay
stop 3 kasama ng tour: buksan ito sa hintuang iyon
lesson a15257a~30.a112427~30 ang sarili mong aralin, kasama ng tour=lesson: mga ID ng lugar ayon sa pagkakasunod, bawat isa ay may taon kung kailan ito ipapakita (~-585 para sa 586 BK: tulad ng year, ang 1 BK ay 0); bawat hintuan ay nakakakuha ng talata ng lugar na pinakamalapit sa taong iyon, ang layo, ang oras kung lalakarin at ang anyo ng lupa. Ang button na “Idagdag sa aralin” sa card ng lugar ay bumubuo ng parehong mga link
title Paul%20in%20Galatia kasama ng lesson: ang pangalan ng aralin, hanggang 80 character, sa ulo ng paglalakbay nito at ng naka-print nitong papel
locale en wika: en, ru, uk, es, pt, de, fr, it, nl, pl o cs
camera 35.2,31.8,7,30,0 longhitud, latitud, zoom, pitch, bearing
hide relief,ancient mga patong na papatayin: borders, places, relief, routes, roads, ancient

Ang pinakamadaling paraan para bumuo ng tanawin ay ihanda ito sa buong globo at kopyahin ang URL: gumagana ang parehong mga parameter pagkatapos ng /embed/v1.

Mga mensahe

Nag-uusap ang globo at ang iyong pahina sa pamamagitan ng postMessage. Bawat mensahe ay isang object na may type at v: 1. Ang ipinapadala lamang ng globo ay ang nangyayari sa mapa, at hindi kailanman anumang makakakilala sa mambabasa; tumatanggap lamang ito ng mga mensahe mula sa pahinang may hawak ng frame.

Mula sa globo

Type Payload Kailan
hg:ready { view } naiguhit na ang mapa
hg:view-changed { view } nagbago at tumigil na ang taon, lugar, paglalakbay o camera
hg:verse-clicked { osis } nag-click ang mambabasa ng isang talata, hal. "Acts.16.12"
hg:error { code, message } hindi nai-load ang mapa o ang datos nito

Naglalaman ang view ng year, locale at layers at, kung itinakda, ng place, tour, stop, ref at camera.

Papunta sa globo

Type Payload Epekto
hg:set-view { view } itakda ang taon, kabanata (ref), lugar, mga patong o camera; kapag may tour (at stop), magsisimula ang paglalakbay at hindi papansinin ang iba pang field; nagbabago lamang ang wika sa pamamagitan ng hg:set-locale
hg:set-locale { locale } palitan ang wika

Halimbawa: sinusundan ng mapa ang iyong mambabasa

const globe = document.querySelector("iframe").contentWindow;

// When your reader opens a chapter, show it on the map.
function showChapter(osis) {
  globe.postMessage({ type: "hg:set-view", v: 1, view: { ref: osis } }, "*");
}

// When a verse is clicked on the map, open it in your reader.
window.addEventListener("message", (e) => {
  if (e.source !== globe) return;
  if (e.data?.type === "hg:verse-clicked") openVerse(e.data.osis);
});

Mga lugar sa anumang teksto

Isa pang linya ang nag-uugnay sa globo ng mga lugar sa Biblia na binabanggit ng sarili mong teksto (isang artikulo, isang sermon, isang plano sa pagbabasa). Ituro ang isang pangalan, o i-tap ito sa telepono, at ipapakita ng isang card kung ano ang lugar, nasaan ito ngayon, ilang talata ang bumabanggit dito at kung saan ito matatagpuan sa mapa; dinadala ng card ang mambabasa sa globo. 

<script src="{{hgPlacesSrc}}" integrity="{{hgPlacesIntegrity}}" crossorigin="anonymous" data-scope="article" charset="utf-8" defer></script>

May bersiyon ang address, at ang integrity hash ang nagtatakda ng eksaktong nilalaman nito: tatakbo lamang ng browser ang script kung iyon mismo ang file. Ang bagong bersiyon ay may bagong address; nananatili ang mga luma kung ano ang mga ito.

Attribute Ano ang ginagawa nito
data-scope kung saan hahanapin, bilang CSS selector; ang buong pahina bilang default
data-locale ang wika ng teksto, isa sa mga wika ng site: cs, de, en, es, fr, it, nl, pl, pt, ru, uk; bilang default, ang lang ng pahina; anumang ibang wika ay babalik sa Ingles
data-every iugnay ang bawat banggit, hindi lamang ang una sa bawat lugar
data-theme light o dark para sa card; bilang default, sinusunod nito ang sistema ng mambabasa

Ang mga pangalang tumuturo lamang sa isang lugar ang iniuugnay. Ang pangalang pinagsasaluhan ng dalawang lugar (Antioquia sa Siria at Antioquia sa Pisidia), ng isang lugar at isang tao (Juda), o ng isang lugar at isang karaniwang salita ay nananatiling payak na teksto, gayundin ang pangalang kadalasang ginagamit ng mismong mga talata ng Biblia para sa ibang bagay (ang “Kades” doon ay Kades-barnea, hindi ang Kades ng database). Ang pangalan ng lugar na pangalan din ng isang tao (Jordan, Saron) ay hindi ginagalaw kapag katabi ito ng isa pang salitang may malaking titik: ang Jordan Smith ay isang tao, hindi ang ilog. Sa Ruso, Ukrainiano, Polako at Czech, natatagpuan ang mga pangalan sa kanilang mga binagong anyo (“в Египте”, “w Jerozolimie”, “v Jeruzalémě”), at ang mga pangalang Aleman ay sa genitive din (“Jerusalems”). Hindi ginagalaw ang mga link, code, field ng form, button at heading.

Walang dependency ang script at hindi ito nagtatakda ng cookie. Binabasa nito ang isang file ng mga pangalan mula sa globo (mga 20 hanggang 35 KB sa network depende sa wika, dagdag ang 7 KB ng script), nang hindi ipinapadala ang address ng iyong pahina bilang referrer, at binabago lamang nito ang mga pangalang iniuugnay nito. Gumagana ito sa ilalim ng mahigpit na Content Security Policy na pinahihintulutan ang address ng globo sa script-src at connect-src. Para sa tekstong idinaragdag ng iyong pahina nang mas huli, tawagin ang HistoryGlobePlaces.scan(element) kapag na-render na ang teksto: hinahati ng script ang mga text node, kaya sa isang pahinang React o Vue, patakbuhin ito sa nilalamang hindi na muling nire-render ng framework.

Katatagan

Ang /embed/v1 ay isang kontrata: sa loob ng v1, mga parameter at mensahe ay idinaragdag lamang, hindi kailanman binabago o inaalis. Ang pagbabagong makakasira ay ilalabas bilang /embed/v2, at patuloy na gagana ang v1.
