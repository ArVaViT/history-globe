--- title: Pag-embed description: Ilagay ang globo sa sarili mong site sa isang linya — ang mapa ng isang kabanata, lugar, taon o paglalakbay — at kontrolin ito mula sa iyong pahina. ---

Tumatakbo ang globo sa loob ng anumang pahina bilang isang iframe. Isang linya ang nagpapakita ng mapa ng isang kabanata sa tabi ng sipi sa iyong pahina; ilang mensahe ang nagpapanatili ng pagkakasabay ng dalawa.

Mabilis na simula

<iframe
  src="{{site}}/embed/v1?ref=Acts.16&locale=tl"
  title="Mapa ng Gawa 16"
  style="width: 100%; height: 480px; border: 0; border-radius: 12px"
  allow="fullscreen"
  loading="lazy"
></iframe>
  • Pinupuno ng mapa ang frame at bumubukas sa mga lugar ng Gawa 16, sa taon ng mga pangyayari nito.
  • Itaas: ang kabanata. Piliin ito para ilista ang mga lugar nito ayon sa pagkakasunod na binabanggit ng teksto; pumili ng lugar para buksan ang card nito.
  • Ibaba: ang taon. Piliin ito para buksan ang slider ng panahon.
  • Binubuksan ng isang link ang parehong tanawin sa buong globo sa bagong tab. Ipinapakita ang mga kredito sa mismong mapa, ayon sa hinihingi ng mga lisensya ng datos.
  • Gumagana ang frame hanggang sa lapad ng isang telepono; sapat na ang taas na 480 px.

Isang kabanata o isang sipi

Tumatanggap ang ref ng reperensiyang OSIS na may mga pinaikling pangalan ng aklat sa Ingles at bilang ng talata sa Ingles:

Halaga Ipinapakita
Acts.16 isang kabanata
Gen.12-Gen.13 hanggang tatlong kabanata
Acts.16.11-Acts.16.15 isang sipi
Ruth isang buong aklat

Lumilipat ang mapa sa taon ng sipi: ang naitalang taon ng mga kabanata nito (may petsa ang mga kabanata ng {{chapter_books}} aklat), o kung wala, ang taon ng paglalakbay na sumasaklaw dito; ang isang buong aklat ay kinukuha ang taon ng paglalakbay na may pinakamaraming hintuan dito. Ang sipi na walang alinman sa dalawa ay pinananatili ang kasalukuyang taon ng mapa.

Mga parameter

Parameter Halimbawa Kahulugan

year -999 taon, sa astronomikal na pagbibilang: ang 1 BK ay 0, ang 1000 BK ay -999

lesson a15257a~30.a112427~30 ang sarili mong aralin, kasama ng tour=lesson: mga ID ng lugar ayon sa pagkakasunod, bawat isa ay may taon kung kailan ito ipapakita (~-585 para sa 586 BK: tulad ng year, ang 1 BK ay 0); bawat hintuan ay nakakakuha ng talata ng lugar na pinakamalapit sa taong iyon, ang layo, ang oras kung lalakarin at ang anyo ng lupa. Ang button na “Idagdag sa aralin” sa card ng lugar ay bumubuo ng parehong mga link
title Paul%20in%20Galatia kasama ng lesson: ang pangalan ng aralin, hanggang 80 character, sa ulo ng paglalakbay nito at ng naka-print nitong papel
locale en wika, isa sa {{locale_codes}}
camera 35.2,31.8,7,30,0 longhitud, latitud, zoom, pitch, bearing; kasama ng place, bubukas ang mapa sa camera na ito na napili ang lugar, sa halip na lumipad dito

ui map ang mapa lamang, para sa pahinang may sariling paghahanap at kahon ng lugar: walang card ng lugar, walang bar ng kabanata, nakatiklop ang taon; nananatili ang link sa globo. Minamarkahan ng singsing ang napiling lugar, at ang pag-click sa bahagi ng mapa na walang lugar ay nag-aalis ng pagpili (tingnan ang halimbawa)
hide relief,battles mga patong na papatayin: borders, places, relief, routes, roads, battles

Ang pinakamadaling paraan para bumuo ng tanawin ay ihanda ito sa buong globo at kopyahin ang URL: gumagana ang parehong mga parameter pagkatapos ng /embed/v1.

Mga mensahe

Nag-uusap ang globo at ang iyong pahina sa pamamagitan ng postMessage. Bawat mensahe ay isang object na may type at v: 1. Ang ipinapadala lamang ng globo ay ang nangyayari sa mapa, at hindi kailanman anumang makakakilala sa mambabasa, kaya nagpapadala ito sa magulang na pahina anuman ang pinagmulan nito (target "*"); tumatanggap lamang ito ng mga mensahe mula sa pahinang may hawak ng frame.

Mula sa globo

Type Payload Kailan
hg:ready { view } naiguhit na ang mapa
hg:view-changed { view } nagbago at tumigil na ang taon, lugar, paglalakbay o camera (mga 400 ms pagkatapos ng huling pagbabago), mambabasa man o ang iyong hg:set-view ang nagbago nito. Kapag lumilipad ang mapa sa bagong napiling lugar, dumarating ito nang isang beses, dala ang bagong lugar at ang camera na iniwan ng mapa, at muli kapag natapos ang paglipad
hg:place-clicked { place } nag-click ang mambabasa ng lugar sa mapa, pati ang napili na; nauuna ito sa hg:view-changed na dulot ng click
hg:verse-clicked { osis } nag-click ang mambabasa ng isang talata sa card ng lugar, hal. "Acts.16.12"
hg:error { code, message } hindi nai-load ang mapa o ang datos nito: ang code ay "map" o "data"

Naglalaman ang view ng year, locale at layers at, kung itinakda, ng place, tour, stop, ref at camera. Ang view na walang place ay nangangahulugang walang napiling lugar. Ang camera ay isang object, { center: [35.2, 31.8], zoom: 7, pitch: 30, bearing: 0 }, hindi ang string ng address; binibigyan ng layers ang bawat layer ng true o false: { relief: false, battles: false }.

Papunta sa globo

Type Payload Epekto
hg:set-view { view } itakda ang taon, kabanata (ref), lugar, mga patong o camera; kapag may tour (at stop), magsisimula ang paglalakbay at hindi papansinin ang iba pang field; nagbabago lamang ang wika sa pamamagitan ng hg:set-locale. Inaalis ng place: null ang pagpili at tinatapos ang paglalakbay na tumatakbo. Muling lilipad ang mapa sa lugar na napili na, maliban kung may camera din ang tanawin. Binabalewala ang ID ng lugar na wala sa mapa
hg:set-locale { locale } palitan ang wika
  • Hintayin ang hg:ready bago ka magpadala ng anuman: nawawala ang mensaheng ipinadala habang naglo-load pa ang mapa.
  • Ituring ang hg:view-changed na kasalukuyang kalagayan, hindi bilang ginawa ng mambabasa: sumusunod ito sa sarili mong hg:set-view at sa bawat galaw ng camera. Ang pahinang nagpapadala pabalik ng buong tanawin gaya ng pagkakasabi rito, kasama ang camera, ay hindi nagsisimula ng loop o ng paglipad. Huwag sagutin ang hg:view-changed ng hg:set-view na place lamang ang laman: kapag walang camera, lilipad pabalik ang mapa sa lugar na iyon, palayo sa kung saan ito inilipat ng mambabasa.

Mga ID ng lugar

Ang lugar sa Bibliya ay may ID ng OpenBible: a na sinusundan ng anim na heksadesimal na digit, gaya ng af2161c (Capernaum). Ang mga lugar ng sinaunang mundo na hindi binabanggit ng Bibliya (Gamla, Sepphoris, Pompeya) ay may numero ng Pleiades sa halip (ang Gamla ay 678146) o, kung wala nito, ang kanilang item sa Wikidata (ang Constantinopla ay Q16869). Parehong uri ay maaaring dumating sa view.place at hg:place-clicked, at parehong tinatanggap ng hg:set-view; kung OpenBible lamang ang mga lugar sa iyong datos, subukan ang anyo bago ka maghanap ng isa. Sa {{openbible}} lugar ng OpenBible, {{absent}} ang wala sa mapa (hindi isinama, o walang anumang punto); binabalewala ang kanilang mga ID.

Halimbawa: sinusundan ng mapa ang iyong app ng Biblia 

const globe = document.querySelector("iframe").contentWindow;
const globeOrigin = "{{site}}";

// Kapag nagbukas ng kabanata ang iyong app ng Biblia, ipakita ito sa mapa.
function showChapter(osis) {
  globe.postMessage({ type: "hg:set-view", v: 1, view: { ref: osis } }, globeOrigin);
}

// Kapag na-click ang isang talata sa mapa, buksan ito sa iyong app ng Biblia.
window.addEventListener("message", (e) => {
  if (e.source !== globe || e.origin !== globeOrigin) return;
  if (e.data?.type === "hg:verse-clicked") openVerse(e.data.osis);
});

Halimbawa: ang mapa sa tabi ng sarili mong kahon ng lugar

<iframe src="{{site}}/embed/v1?ui=map&place=af2161c&locale=en" title="Map"></iframe>
const globe = document.querySelector("iframe").contentWindow;
const globeOrigin = "{{site}}";
let ready = false;

window.addEventListener("message", (e) => {
  if (e.source !== globe || e.origin !== globeOrigin) return;
  const m = e.data;
  if (m?.type === "hg:ready") ready = true;
  // Ang tanawin ngayon: may napiling lugar, o wala. Madalas itong dumating: dapat walang gawin ang
  // showPlace kapag ipinapakita na ang lugar.
  if (m?.type === "hg:ready" || m?.type === "hg:view-changed") {
    if (m.view.place) showPlace(m.view.place);
    else hidePlace();
  }
  // Bawat click sa isang lugar, pati ang napili na: buksan muli ang iyong kahon.
  if (m?.type === "hg:place-clicked") showPlace(m.place);
});

// Pumili ng lugar ang iyong paghahanap: piliin ito at lumipad doon (muli, kung napili na).
function pickPlace(id) {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: id } }, globeOrigin);
}

// Isinara ang iyong kahon: alisin ang pagpili sa mapa.
function closeBox() {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: null } }, globeOrigin);
}
  • Minamarkahan ng singsing na lumalaki at kumukupas ang napiling lugar, kaya nahahanap ito ng mata nang walang tumatakip sa mapa; para sa mambabasang humingi ng mas kaunting galaw, nananatiling hindi gumagalaw ang singsing.
  • Ang pag-click sa bahagi ng mapa na walang lugar ay nag-aalis ng pagpili ng lugar; magpapatuloy ang paglalakbay na tumatakbo. Ang double-click (na nag-zoom) at ang pag-click na nagpapahinto sa gumagalaw na mapa ay walang inaalis. Ang place: null mula sa iyong pahina ay nag-aalis ng lugar at tinatapos ang paglalakbay.
  • Tumatakbo ang isang paglalakbay sa mapa (ang ruta, mga hintuan at taon nito) nang walang card nito: ang pahina mo ang gumagalaw rito gamit ang hg:set-view at { tour, stop }. Iginuguhit ng measure ang linya nito, gaya sa bawat frame.
  • Hindi ipinapadala ang hg:verse-clicked: nasa card ng lugar ang mga talata, na hindi isinasama ng mode na ito.

Mga lugar sa anumang teksto

Isa pang linya ang nag-uugnay sa globo ng mga lugar sa Biblia na binabanggit ng sarili mong teksto (isang artikulo, isang sermon, isang plano sa pagbabasa). Ituro ang isang pangalan, o i-tap ito sa telepono, at ipapakita ng isang card kung ano ang lugar, nasaan ito ngayon, ilang talata ang bumabanggit dito at kung saan ito matatagpuan sa mapa; dinadala ng card ang mambabasa sa globo. 

<script src="{{hgPlacesSrc}}" integrity="{{hgPlacesIntegrity}}" crossorigin="anonymous" data-scope="article" charset="utf-8" defer></script>

May bersiyon ang address, at ang integrity hash ang nagtatakda ng eksaktong nilalaman nito: tatakbo lamang ng browser ang script kung iyon mismo ang file. Ang bagong bersiyon ay may bagong address; nananatili ang mga luma kung ano ang mga ito.

Nasa ilalim ng lisensyang MIT ang script, at nasa pampublikong dominyo ang mga halimbawang code sa pahinang ito (CC0 1.0): gamitin ang mga ito sa anumang site, anuman ang lisensya nito.

Attribute Ano ang ginagawa nito
data-scope kung saan hahanapin, bilang CSS selector; ang buong pahina bilang default
data-locale ang wika ng teksto, isa sa mga wika ng site: {{locale_codes}}; bilang default, ang lang ng pahina; anumang ibang wika ay babalik sa Ingles
data-every iugnay ang bawat banggit, hindi lamang ang una sa bawat lugar
data-theme light o dark para sa card; bilang default, sinusunod nito ang sistema ng mambabasa

Ang mga pangalang tumuturo lamang sa isang lugar ang iniuugnay. Ang pangalang pinagsasaluhan ng dalawang lugar (Antioquia sa Siria at Antioquia sa Pisidia), ng isang lugar at isang tao (Juda), o ng isang lugar at isang karaniwang salita ay nananatiling payak na teksto, gayundin ang pangalang kadalasang ginagamit ng mismong mga talata ng Biblia para sa ibang bagay (ang “Kades” doon ay Kades-barnea, hindi ang Kades ng database). Ang pangalan ng lugar na pangalan din ng isang tao (Jordan, Saron) ay hindi ginagalaw kapag katabi ito ng isa pang salitang may malaking titik: ang Jordan Smith ay isang tao, hindi ang ilog. Sa Ruso, Ukrainiano, Polako, Czech, Serbian, Hungarian, Finnish at Romanian, natatagpuan ang mga pangalan sa kanilang mga binagong anyo (“в Египте”, “w Jerozolimie”, “v Jeruzalémě”), at ang mga pangalang Aleman, Swedish, Danish at Norwegian ay sa genitive din (“Jerusalems”). Hindi ginagalaw ang mga link, code, field ng form, button at heading.

Walang dependency ang script at hindi ito nagtatakda ng cookie. Binabasa nito ang isang file ng mga pangalan mula sa globo (mga {{names_kb_min}} hanggang {{names_kb_max}} KB sa network depende sa wika, dagdag ang {{script_kb}} KB ng script), nang hindi ipinapadala ang address ng iyong pahina bilang referrer, at binabago lamang nito ang mga pangalang iniuugnay nito. Gumagana ito sa ilalim ng mahigpit na Content Security Policy na pinahihintulutan ang address ng globo sa script-src at connect-src. Para sa tekstong idinaragdag ng iyong pahina nang mas huli, tawagin ang HistoryGlobePlaces.scan(element) kapag na-render na ang teksto: hinahati ng script ang mga text node, kaya sa isang pahinang React o Vue, patakbuhin ito sa nilalamang hindi na muling nire-render ng framework.

Katatagan

Ang /embed/v1 ay isang kontrata: sa loob ng v1, mga parameter at mensahe ay idinaragdag lamang, hindi kailanman binabago o inaalis. Ang pagbabagong makakasira ay ilalabas bilang /embed/v2, at patuloy na gagana ang v1.
