--- title: Mga sanggunian at lisensya description: Ang mga dataset, teksto, litrato at software na pinagmulan ng History Globe, kasama ang kanilang mga may-akda at lisensya, at kung ano ang ginagawa ng site sa iyong datos. ---

Itinayo ang History Globe sa gawa ng mga iskolar at ng mga proyekto ng bukas na datos. Ginagamit ang kanilang datos sa ilalim ng kanilang mga lisensya, at itinatala ang aming mga pagbabago. Hindi nangangahulugan ang paglilista ng isang sanggunian na sinusuportahan ng mga may-akda nito ang History Globe.

Mga teksto ng Biblia

Ang saling Sinodal ng Ruso (1876), ang World English Bible at ang King James Version, pawang nasa pampublikong dominyo; ang mga elektronikong teksto ay mula sa eBible.org. Sinusuri laban sa mga ito ang mga pangalan at ang pag-iral ng mga talata; ang mga sipi sa mga paglalakbay at ang mga teksto ng talata ay mula sa saling Sinodal at sa King James Version.

Sa ibang mga wika, ang mga sipi at teksto ng talata ay mula sa isang klasikong edisyon ng bawat isa na nasa pampublikong dominyo: Ukrainiano, Panteleimon Kulish (1871); Espanyol, Reina-Valera (1909); Portuges, ang World Portuguese Bible; Aleman, Luther (1912); Pranses, Louis Segond (1910); Italyano, ang Riveduta (1927); Olandes, ang Statenvertaling (edisyon ng 1917); Czech, ang Biblia ng Kralice (1613), lahat mula sa eBible.org; Polako, ang Biblia ng Gdańsk (edisyon ng 1881), mula sa aklatan ng SWORD ng CrossWire. Kung iba ang bilang ng kabanata sa isang edisyon kaysa sa KJV, iniiwan ng card ang mga talata nito at pinananatili ang link. Sa Biblia ng Gdańsk, ang isang salita para sa mga Cushita, na nakakasakit ngayon, ay pinapalitan ng „Etiopczyk”, gaya sa mga makabagong Biblia sa Polako.

Mga litrato

Ang {{photos}} litrato ng mga lugar ay galing sa Wikimedia Commons, at ang mga nasa pampublikong dominyo lamang o nasa ilalim ng CC0 o CC BY ang ginagamit. Nakasaad sa ilalim ng bawat litrato ang may-akda, lisensya at link sa file; para sa pinagtatalunang lugar, sinasabi ng caption kung alin sa mga iminumungkahing pook ang ipinapakita nito. Binabago ang laki at ginugupit ang mga litrato para magkasya sa frame.

Software

Ginagamit ng site ang MapLibre GL JS (BSD-3-Clause), React (MIT), ang mga icon ng Lucide (ISC) at Feather (MIT), at ang mga typeface na Golos Text at Literata (SIL Open Font License). Ang kanilang mga teksto ng lisensya: third-party.txt, lucide-icons.txt; kasama ng mga file ng MapLibre ang lisensya nito.
