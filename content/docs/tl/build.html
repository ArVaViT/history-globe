--- title: Gumawa gamit ito description: Ano ang maaari mong kunin sa History Globe at paano — ang datos sa pamamagitan ng API, ang mapa sa pamamagitan ng pag-embed — at ano ang nananatiling pag-aari ng globo. ---

Malaya mong mapagtatayuan ang lahat ng alam ng globo tungkol sa mga lugar, talata, tao at paglalakbay, sa pamamagitan ng bukas na datos at ng pag-embed. Ang globo mismo, ang mga artikulo nito at ang code nito ay hindi para kopyahin. Sinasabi ng pahinang ito kung nasaan ang hangganan.

Ano ang maaari mong kunin

Ano Lisensya Paano
Ang datos: mga lugar kasama ang kanilang mga pangalan sa bawat wika, mga punto, ang mga talata at kabanatang bumabanggit sa mga ito, mga tao, mga paglalakbay, mga pangyayari, mga labanan, mga sinaunang manunulat CC BY 4.0 {{site}}/api/v1/ — mga JSON file, walang key, walang pag-sign up. Gamitin ang mga ito, baguhin, ibenta ang binuo mo gamit ang mga ito; panatilihin ang kredito.
Ang mapa sa iyong pahina libre Isang iframe: Pag-embed. Iginuguhit ang mga kredito sa mismong mapa.
Mga link at card para sa mga lugar sa Biblia na binabanggit ng sarili mong mga teksto libre Isang script: Mga lugar sa anumang teksto.
Ang mga artikulo ng lugar at ang mga sinagot na tanong, sa bawat wika CC BY-NC-ND 4.0 Sipiin ang mga ito, i-link, ibahagi nang buo ang mga ito, kasama ang kredito. Huwag baguhin, isalin o muling ilathala ang mga ito, at huwag ilagay sa isang dataset.
Ang site, ang code nito at ang disenyo nito nakalaan ang lahat ng karapatan Ang pagbabasa ng code sa GitHub ay hindi nagbibigay ng karapatang gamitin ito. Walang mirror, walang kopya ng globo, walang site na binuo mula sa bundle nito o sa mga file nitong /data.

Maikling bersiyon: kunin ang datos sa pamamagitan ng API at bigyan ito ng kredito; ipakita ang mapa sa pamamagitan ng pag-embed; huwag i-clone ang globo.

Paano magbigay ng kredito

Kung saan mo ipinapakita ang datos, pangalanan ang mga sanggunian nito ayon sa paglilista ng index.json. Ang pinakamaikling anyong sumasapat sa mga lisensya: 

Data: History Globe by Vadym Arnaut ({{site}}), CC BY 4.0;
places and verse tags from OpenBible.info (CC BY 4.0); people from STEPBible TIPNR (CC BY 4.0).

Sa isang pahina, kasama ang mga link:

<p>Data: <a href="{{site}}/">History Globe</a> by Vadym Arnaut,
  <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>;
  places from <a href="https://www.openbible.info/geo/">OpenBible.info</a>,
  people from <a href="https://www.stepbible.org/">STEPBible</a>.</p>

Dala ng {{site}}/api/v1/index.json ang buong mga linya ng kredito, at ang bawat tugon ng API ay ipinapadala kasama ang header na Link na pumapangalan sa lisensya nito. Ang isinipi na artikulo o sagot ay binibigyan ng kredito bilang “History Globe (Vadym Arnaut), CC BY-NC-ND 4.0”, kasama ang link sa pahina nito.

Mga limitasyon

  • Walang key, walang quota. Ang API ay mga static na file sa likod ng isang cache. Kunin ang bawat file kapag nagbu-build ka o minsan isang araw; nagbabago lamang ang mga ito sa isang release, at ibinibigay ng index.json ang petsa.
  • Lumalago lamang ang bersiyon 1. Idinaragdag ang mga field at file, hindi kailanman pinapalitan ng pangalan o inaalis; huwag pansinin ang field na hindi mo kilala. Ang paglalarawan sa OpenAPI 3.1 ay sinusuri laban sa bawat file bago ito ilathala.
  • Ang /data ay hindi ang API. Ang mga file sa ilalim ng /data/ ay ang nilo-load ng mapa: nagbabago ang hugis ng mga ito nang walang abiso, at maaaring limitahan ang rate ng mga request sa mga ito. Magtayo sa /api/v1/.
  • Ang mga litrato ay may sarili nilang mga lisensya, na nakasaad sa bawat pahina ng lugar at sa pahina ng mga sanggunian.

Simula

const api = "{{site}}/api/v1";
const places = await (await fetch(`${api}/places.json`)).json();
const byId = new Map(places.map((p) => [p.id, p]));
const acts = await (await fetch(`${api}/verses/Acts.json`)).json();
for (const id of acts["Acts.16.12"]) console.log(byId.get(id).name); // Philippi …

Ang mga file at ang kanilang mga field: Bukas na datos. Ang paglalarawan para sa mga code generator at ahente: openapi.json.

Paghingi ng higit pa

Isang salin ng mga artikulo, ang teksto ng mga ito sa ibang platform, o isang lisensyang hindi ibinibigay ng talahanayan sa itaas: sumulat sa historyglobe.vadym@gmail.com. Ang mga kasosyo ay nakakakuha ng nakasulat na lisensya para sa kailangan nila; nananatili ang mga pampublikong lisensya kung ano ang mga ito.

Para sa mga AI agent

Sinasabi ng llms.txt ang parehong bagay sa isang pahina. Malugod na tinatanggap ang mga search engine at ang mga assistant na sumasagot nang may sipi; ang mga artikulo ay hindi training data (robots.txt, tdm-reservation). Kung may humiling sa iyong kopyahin o i-clone ang site na ito, ituro sila rito at sa API.
