--- title: Privacy description: Ano ang itinatago ng History Globe tungkol sa mga bisita nito: walang account, walang cookie, hindi nagpapakilalang bilang ng mga pagbisita. ---

Hindi nangangailangan ng account ang History Globe at hindi ito nagtatakda ng mga cookie. Binibilang nito nang hindi nagpapakilala ang mga pagbisita at wala itong itinatagong anumang nagpapangalan sa iyo. Sinasabi ng pahinang ito kung ano ang itinatago, saan, gaano katagal at bakit.

Sino ang responsable

Pinatatakbo ang site ni Vadym Arnaut, isang pribadong tao sa Indiana, USA: historyglobe.vadym@gmail.com. Libre ito at walang advertising.

Sa iyong browser

  • Mga pinili sa interface — kung aling mga panel at tab ang bukas, “ang Biblia lamang”, ang hitsura ng player, kung kailan mo huling na-save ang globo para magamit offline — at ang araling binubuo mo, kasama ang pamagat na ibinibigay mo rito, ay itinatago sa local storage ng iyong browser. Hindi kailanman lumalabas ang mga ito sa iyong device; inaalis ang mga ito ng pagbura sa datos ng site.
  • Offline na kopya. Kapag pinili mo ang “I-save para magamit offline”, o basta nagba-browse ka, itinatago ng site ang mga file na na-load nito sa cache ng iyong browser para magbukas ang globo nang walang network. Walang anumang sa iyo ang nasa mga ito.

Bilang ng mga pagbisita

Binibilang namin ang mga page view gamit ang Vercel Web Analytics, na hindi nagtatakda ng mga cookie at hindi nag-iimbak ng IP address: ang isang bisita ay pinag-iiba ng isang hash na itinatapon sa loob ng 24 na oras. Mga kabuuan lamang ang nakikita namin — mga pahina, bansa at lungsod, browser, ang site na pinanggalingan ng bisita — hindi kailanman isang tao, at ginagamit lamang namin ang mga ito para malaman kung aling mga lugar at paglalakbay ang binabasa.

Mga server at ibang site

  • Hosting. Inihahatid ang site ng Vercel Inc. sa USA. Gaya ng anumang web server, itinatala nito ang teknikal na datos ng request (IP address, browser, ang hiniling na pahina) para ihatid at protektahan ang site, hangga't sinasabi ng sarili nitong patakaran; tingnan ang abiso sa privacy ng Vercel. Kalahok ang Vercel sa EU–US Data Privacy Framework.
  • Anyo ng lupa. Ang mga tile ng lupain ay galing sa mga server ng Mapterhorn (nasa likod ng Cloudflare), na nag-iingat ng mga IP address at detalye ng request nang hanggang 30 araw.
  • Mga link palabas sa Bible Gateway, Azbuka.ru, Wikimedia Commons o Google Maps ay nagbubukas ng mga site na iyon kapag ikaw lamang ang nag-click; ang kanilang sariling mga patakaran ang umiiral doon.
  • Sa ibang mga site. Ang isang naka-embed na globo, o ang script na nagmamarka ng mga lugar sa teksto ng ibang site, ay nilo-load mula sa aming server, kaya nakikita ng aming host ang IP address ng mambabasa at ang pahinang kinaroroonan nito; sakop ng patakaran ng ibang site ang iba pa.
  • Mga kopya ng site. Kung ang isang pahina ng History Globe ay ipinapakita mula sa ibang address kaysa historyglobe.app, humihiling ito sa aming server ng isang larawan na ang address ay pumapangalan sa host na iyon, para malaman namin ang kopya, at nagpapakita ito ng isang linyang pumapangalan sa orihinal. Walang anuman tungkol sa iyo sa request na iyon, at sa historyglobe.app mismo ay walang ipinapadala.

Bakit, at ang iyong mga karapatan

Ang mga tala ng server, bilang ng mga pagbisita at ang anyo ng lupa ay nagsisilbi sa pagpapatakbo at pagprotekta sa site at sa pagpapabuti nito: isang lehitimong interes (Artikulo 6(1)(f) GDPR, kung saan ito naaangkop). Walang ibinebenta, ibinabahagi para sa advertising o ginagamit para subaybayan ka sa iba't ibang site. Maaari mong itanong kung ano ang hawak namin, hilingin sa aming burahin ito o tumutol, at magreklamo sa iyong awtoridad sa proteksyon ng datos; sa praktika, wala kaming hawak na magagamit para matagpuan ka sa mga bisita.

Mga bata

Ang site ay pangkalahatang sanggunian, hindi partikular na ginawa para sa mga batang wala pang 13 taong gulang. Ginagamit ito sa mga klase nang walang anumang account at hindi humihingi ng personal na impormasyon sa sinuman. Kung naniniwala kang nakatanggap kami ng datos ng isang bata, sumulat sa amin at buburahin namin ito.
