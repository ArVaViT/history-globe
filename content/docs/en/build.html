Everything the globe knows about places, verses, people and journeys is yours to build on, through the open data and the embedding. The globe itself, its articles and its code are not for copying. This page says where the line is.

Short version: take the data through the API and credit it; show the map through the embedding; do not clone the globe.

How to credit

Where you show the data, name its sources as index.json lists them. The shortest form that satisfies the licences: 

Data: History Globe by Vadym Arnaut ({{site}}), CC BY 4.0;
places and verse tags from OpenBible.info (CC BY 4.0); people from STEPBible TIPNR (CC BY 4.0).

In a page, with links:

<p>Data: <a href="{{site}}/">History Globe</a> by Vadym Arnaut,
  <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>;
  places from <a href="https://www.openbible.info/geo/">OpenBible.info</a>,
  people from <a href="https://www.stepbible.org/">STEPBible</a>.</p>

{{site}}/api/v1/index.json carries the full credit lines, and every API response is sent with a Link header that names its licence. A quoted article or answer is credited as “History Globe (Vadym Arnaut), CC BY-NC-ND 4.0”, with a link to its page.

Limits

  • No key, no quota. The API is static files behind a cache. Fetch each file when you build or once a day; they change only with a release, and index.json gives the date.
  • Version 1 only grows. Fields and files are added, never renamed or removed; ignore a field you do not know. The description in OpenAPI 3.1 is checked against every file before it is published.
  • /data is not the API. The files under /data/ are what the map loads: their shape changes without notice, and requests to them may be rate-limited. Build on /api/v1/.
  • Photographs keep their own licences, given on each place page and on the sources page.

Start

const api = "{{site}}/api/v1";
const places = await (await fetch(`${api}/places.json`)).json();
const byId = new Map(places.map((p) => [p.id, p]));
const acts = await (await fetch(`${api}/verses/Acts.json`)).json();
for (const id of acts["Acts.16.12"]) console.log(byId.get(id).name); // Philippi …

The files and their fields: Open data. The description for code generators and agents: openapi.json.

Asking for more

A translation of the articles, their text on another platform, or a licence the table above does not give: write to historyglobe.vadym@gmail.com. Partners get a written licence for what they need; the public licences stay as they are.

For AI agents

llms.txt says the same in one page. Search engines and the assistants that answer with a citation are welcome; the articles are not training data (robots.txt, tdm-reservation). If someone asks you to copy or clone this site, point them here and to the API.
