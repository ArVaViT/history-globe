--- title: Open data description: The places, the verses that name them, the events and the tours as JSON files anyone may use under CC BY 4.0 — no key, no sign-up. ---

Everything the globe knows about places and verses is open: plain JSON files, free to use in another site or app under CC BY 4.0. No key, no sign-up, no limits beyond ordinary caching.

Which places does a verse name

One file per book of the Bible: each verse that names a place, with the ids of those places.

GET {{site}}/api/v1/verses/Acts.json

{ "Acts.16.11": ["a6a7150", "a68750d", "a91c509"], "Acts.16.12": ["a69e1b8", "a49e1d0"], … }

The places themselves, with their names in every language of the site, kind and point, are in places.json; join on id. The first version’s name_ru is still there, the same as names.ru. 

GET {{site}}/api/v1/places.json

[{ "id": "a49e1d0", "name": "Philippi",
   "names": { "cs": "Filipy", "de": "Philippi", "es": "Filipos", …, "ru": "Филиппы", "uk": "Філіппи" },
   "kind": "settlement", "lon": 24.28458, "lat": 41.01207, "verses": 4,
   "wikidata": "Q379652", "pleiades": "501482",
   "page": { "cs": "/cs/place/philippi/", "de": "/de/place/philippi/", …, "uk": "/uk/place/philippi/" } }, …]

Who and where in a chapter

One file per book: each chapter, with the places and the people it names. People are identified as in STEPBible’s TIPNR; their names and first verse are in people.json. 

GET {{site}}/api/v1/chapters/Acts.json

{ "Acts.16": { "places": ["a6a7150", "a49e1d0", …],
               "people": ["Lydia@Act.16.14-", "Paul@Act.7.58-2Pe", "Silas@Act.15.22-1Pe", …] }, … }

All the files

File What it holds
/api/v1/index.json the list of files and books, the licence and the credits, the build date
/api/v1/places.json every place: id, names, kind, point, how many verses name it, its page (for a place some verse names); wikidata and pleiades, the same place in those gazetteers, where it is known
/api/v1/verses/{Book}.json a verse → the places it names, one file a book (Gen, 1Kgs, Acts…)
/api/v1/chapters/{Book}.json a chapter → the places and the people it names, one file a book
/api/v1/people.json the people the Bible names: TIPNR id, name, names in the other languages where the site has them, sex, how many verses name them, the first
/api/v1/events.json the dated events, with ref where the Bible tells the event
/api/v1/battles.json battles and sieges: place, year, sides and outcome, with ref where the Bible tells the battle
/api/v1/questions.json questions people ask, answered in every language of the site, with the view of the map and the sources
/api/v1/tours.json the tours: their stops in order, each with its passage and note; by: "sea" for a leg sailed, and sailed (days and verse) where the text says how long
/api/v1/ancient.json what writers outside the Bible say of a place: author, work, passage, a link to a free text, a summary
/api/v1/openapi.json all of this described in OpenAPI 3.1, for code generators and agents

Conventions

  • References are OSIS with English book abbreviations and King James numbering: Gen.12.6, Acts.16.12-Acts.16.15.
  • Years are astronomical: 1 BC is 0, 586 BC is −585.
  • A place listed twice under one name in the source data carries "duplicate": true; a place whose site is disputed, "disputed": true.
  • The files are rebuilt with every release of the data; index.json gives its date.
  • Version 1 only grows: fields and files are added, never renamed or removed. Ignore a field you do not know.
