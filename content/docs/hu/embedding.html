Az az igeszakasz, amelynek egyik sincs meg, a térkép aktuális évét megtartja.

Üzenetek

A földgömb és az Ön oldala a postMessage-en keresztül kommunikál. Minden üzenet egy type és v: 1 mezőt tartalmazó objektum. A földgömb csak azt küldi, ami a térképen történik, és soha semmit, ami azonosítaná az olvasót, ezért üzeneteit a szülőoldalnak küldi, bármi legyen is annak származása (cél: "*"); üzeneteket csak attól az oldaltól fogad el, amelyik a keretet tartalmazza.

A földgömbtől

Típus Tartalom Mikor
hg:ready { view } a térkép megrajzolódott
hg:view-changed { view } az év, a hely, a túra vagy a kamera megváltozott és megállapodott (az utolsó változás után nagyjából 400 ms-mal), akár az olvasó, akár az Ön hg:set-view üzenete változtatta meg. Amikor a térkép egy újonnan kijelölt helyhez repül, az üzenet egyszer jön az új hellyel és azzal a kamerával, amelyet a térkép elhagyott, majd még egyszer, amikor a repülés véget ér
hg:place-clicked { place } az olvasó egy helyre kattintott a térképen, a már kijelölt helyre is; a kattintás okozta hg:view-changed előtt érkezik
hg:verse-clicked { osis } az olvasó egy helykártyán lévő versre kattintott, például "Acts.16.12"
hg:error { code, message } a térkép vagy az adatai nem tudtak betöltődni: a code értéke "map" vagy "data"

A view tartalmazza a year, locale és layers mezőt, és ha be van állítva, a place, tour, stop, ref és camera mezőt. A place nélküli view azt jelenti, hogy nincs hely kijelölve. A camera objektum, { center: [35.2, 31.8], zoom: 7, pitch: 30, bearing: 0 }, nem a cím karakterlánca; a layers minden réteghez true vagy false értéket ad: { relief: false, battles: false }.

A földgömbhöz

Típus Tartalom Hatás
hg:set-view { view } beállítja az évet, a fejezetet (ref), a helyet, a rétegeket vagy a kamerát; a tour (és stop) megadásakor a túra elindul, a többi mezőt pedig figyelmen kívül hagyja; a nyelv csak a hg:set-locale üzenettel változik. A place: null törli a kijelölést, és véget vet a futó túrának. A már kijelölt helyre újra odarepül, hacsak a nézet nem tartalmaz camera mezőt is. A térképen nem szereplő helyazonosítót figyelmen kívül hagyja
hg:set-locale { locale } nyelvváltás
  • Várjon a hg:ready üzenetre, mielőtt bármit küld: a még töltődő térképnek küldött üzenet elvész.
  • Kezelje a hg:view-changed üzenetet aktuális állapotként, ne az olvasó tetteként: követi az Ön saját hg:set-view üzenetét és a kamera minden mozgását. Az az oldal, amely a teljes nézetet úgy küldi vissza, ahogy kapta, a kamerával együtt, sem hurkot, sem repülést nem indít. Ne válaszoljon a hg:view-changed üzenetre olyan hg:set-view üzenettel, amelyben csak place van: camera nélkül a térkép visszarepül ahhoz a helyhez, el attól, ahová az olvasó mozgatta.

Helyazonosítók

A Biblia helyeinek OpenBible-azonosítójuk van: egy a betű és hat hexadecimális számjegy, például af2161c (Kapernaum). Az ókori világ azon helyeinek, amelyeket a Biblia nem nevez meg (Gamla, Sepphórisz, Pompeji), ehelyett Pleiades-számuk van (Gamla száma 678146), ennek híján pedig Wikidata-elemük (Konstantinápoly eleme Q16869). Mindkét fajta megjelenhet a view.place mezőben és a hg:place-clicked üzenetben, és a hg:set-view mindkettőt elfogadja; ha az Ön adataiban csak OpenBible-helyek vannak, ellenőrizze az azonosító alakját, mielőtt kikeresné. Az OpenBible {{openbible}} helye közül {{absent}} nincs a térképen (kihagytuk őket, vagy egyáltalán nincs pontjuk); az azonosítóikat figyelmen kívül hagyja.

Példa: a térkép követi az olvasót

const globe = document.querySelector("iframe").contentWindow;

// When your reader opens a chapter, show it on the map.
function showChapter(osis) {
  globe.postMessage({ type: "hg:set-view", v: 1, view: { ref: osis } }, "*");
}

// When a verse is clicked on the map, open it in your reader.
window.addEventListener("message", (e) => {
  if (e.source !== globe) return;
  if (e.data?.type === "hg:verse-clicked") openVerse(e.data.osis);
});

Példa: a térkép az Ön saját helymezője mellett

<iframe src="{{site}}/embed/v1?ui=map&place=af2161c&locale=en" title="Map"></iframe>
const globe = document.querySelector("iframe").contentWindow;
let ready = false;

window.addEventListener("message", (e) => {
  if (e.source !== globe) return;
  const m = e.data;
  if (m?.type === "hg:ready") ready = true;
  // A nézet, ahogy most van: egy hely kijelölve, vagy egy sem. Gyakran jön: a showPlace ne
  // csináljon semmit, ha az a hely már látszik.
  if (m?.type === "hg:ready" || m?.type === "hg:view-changed") {
    if (m.view.place) showPlace(m.view.place);
    else hidePlace();
  }
  // Minden kattintás egy helyre, a már kijelöltre is: nyissa meg újra a helymezőjét.
  if (m?.type === "hg:place-clicked") showPlace(m.place);
});

// A keresése kiválasztott egy helyet: jelölje ki, és repüljön hozzá (újra, ha már ki van jelölve).
function pickPlace(id) {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: id } }, "*");
}

// A helymezője bezárult: törölje a kijelölést a térképen.
function closeBox() {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: null } }, "*");
}
  • A kijelölt helyet növekvő és halványuló gyűrű jelöli, így a szem megtalálja, miközben semmi sem takarja a térképet; annak az olvasónak, aki kevesebb mozgást kért, a gyűrű mozdulatlan marad.
  • A térképen bármely helytől távol kattintva törlődik a hely kijelölése; a futó túra megy tovább. A dupla kattintás (amely nagyít) és a mozgó térképet megállító kattintás nem töröl semmit. A place: null az Ön oldaláról törli a helyet és véget vet a túrának.
  • A túra a térképen fut (az útvonala, a megállói és az év) a saját kártyája nélkül: az Ön oldala a hg:set-view üzenettel és a { tour, stop } mezőkkel vezérli. A measure megrajzolja a vonalát, mint minden keretben.
  • A hg:verse-clicked nem érkezik: a versek a helykártyán vannak, amelyet ez a mód elhagy.

Helyek bármilyen szövegben

Még egy sor a földgömbhöz kapcsolja azokat a bibliai helyeket, amelyeket a saját szövege (egy cikk, egy prédikáció, egy olvasási terv) megnevez. Mutasson egy névre, vagy érintse meg telefonon, és egy kártya megmutatja, mi a hely, hol van ma, hány vers nevezi meg, és hol fekszik a térképen; a kártya a földgömbre vezet. 

<script src="{{hgPlacesSrc}}" integrity="{{hgPlacesIntegrity}}" crossorigin="anonymous" data-scope="article" charset="utf-8" defer></script>

A cím verziót tartalmaz, az integritás-hash pedig rögzíti a pontos tartalmát: a böngésző csak akkor futtatja a szkriptet, ha az pontosan ez a fájl. Az új verzió új címet kap; a régiek változatlanok maradnak.

Attribútum Mit csinál
data-scope hol keressen, CSS-szelektorként; alapértelmezés szerint az egész oldalon
data-locale a szöveg nyelve, az oldal egyik nyelve: {{locale_codes}}; alapértelmezés szerint az oldal lang értéke; bármely más nyelv esetén az angolra vált
data-every minden említést összekapcsol, nem csak az egyes helyek első előfordulását

Csak azok a nevek kapnak hivatkozást, amelyek egyetlen helyre mutatnak. Az a név, amelyet két hely (Antiókhia, a szíriai és a pizidiai), egy hely és egy személy (Júda), vagy egy hely és egy közönséges szó oszt meg, sima szöveg marad, ahogyan az a név is, amelyet a Biblia saját versei többnyire másra használnak („Kádes” ott Kádes-Barnea, nem az adatbázis Kádese). Egy hely neve, amely egyben keresztnév is (Jordán, Sáron), békén marad egy másik nagybetűs szó mellett: Jordán Smith személy, nem a folyó. Oroszul, ukránul, lengyelül, csehül, szerbül, magyarul, finnül és románul a neveket ragozott alakjukban is megtalálja („в Египте”, „w Jerozolimie”, „v Jeruzalémě”), a német, svéd, dán és norvég neveket pedig birtokos esetben is („Jerusalems”). A hivatkozásokat, a kódot, az űrlapmezőket, a gombokat és a címsorokat nem érinti.

A szkriptnek nincsenek függőségei, és nem állít be sütiket. A földgömbtől egy névfájlt olvas be (a hálózaton nyelvtől függően körülbelül {{names_kb_min}}–{{names_kb_max}} KB, plusz {{script_kb}} KB szkript), az Ön oldalának címét hivatkozóként nem adja át, és csak azokat a neveket módosítja, amelyeket összekapcsol. Szigorú tartalombiztonsági szabályzat (Content Security Policy) mellett is működik, amely a script-src és a connect-src irányelvben engedélyezi a földgömb címét. Az Ön oldala által később hozzáadott szöveghez hívja meg egyszer a HistoryGlobePlaces.scan(element) függvényt, miután a szöveg megjelent: a szkript felbontja a szövegcsomópontokat, ezért React- vagy Vue-oldalon olyan tartalmon futtassa, amelyet a keretrendszer már nem rajzol újra.

Stabilitás

Az /embed/v1 szerződés: a v1-en belül a paraméterek és az üzenetek csak bővülnek, soha nem változnak és nem szűnnek meg. A visszafelé nem kompatibilis változás /embed/v2 néven jelenik meg, a v1 pedig tovább működik.
