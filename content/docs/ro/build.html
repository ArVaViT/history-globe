Tot ce știe globul despre locuri, versete, persoane și călătorii vă stă la dispoziție ca să construiți pe el, prin datele deschise și prin încorporare. Globul însuși, articolele și codul lui nu sunt de copiat. Această pagină arată unde este limita.

Ce puteți prelua

Ce Licență Cum

Site-ul, codul și designul lui toate drepturile rezervate Faptul că puteți citi codul pe GitHub nu vă dă niciun drept de a-l folosi. Fără oglindiri, fără copii ale globului, fără site-uri construite din bundle-ul lui sau din fișierele lui /data.

Pe scurt: preluați datele prin API și menționați sursa; arătați harta prin încorporare; nu clonați globul.

Cum se menționează sursa

Acolo unde afișați datele, numiți sursele lor așa cum le enumeră index.json. Cea mai scurtă formă care satisface licențele: 

Data: History Globe by Vadym Arnaut ({{site}}), CC BY 4.0;
places and verse tags from OpenBible.info (CC BY 4.0); people from STEPBible TIPNR (CC BY 4.0).

Într-o pagină, cu linkuri:

<p>Data: <a href="{{site}}/">History Globe</a> by Vadym Arnaut,
  <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>;
  places from <a href="https://www.openbible.info/geo/">OpenBible.info</a>,
  people from <a href="https://www.stepbible.org/">STEPBible</a>.</p>

{{site}}/api/v1/index.json conține rândurile complete de mențiune a surselor, iar fiecare răspuns al API-ului este trimis cu un antet Link care îi numește licența. Un articol sau un răspuns citat se menționează ca „History Globe (Vadym Arnaut), CC BY-NC-ND 4.0”, cu un link către pagina lui.

Limite

  • Fără cheie, fără cotă. API-ul este alcătuit din fișiere statice în spatele unui cache. Descărcați fiecare fișier la build sau o dată pe zi; ele se schimbă doar odată cu o lansare, iar index.json dă data.
  • Versiunea 1 doar crește. Câmpurile și fișierele se adaugă, nu sunt niciodată redenumite sau eliminate; ignorați un câmp pe care nu îl cunoașteți. Descrierea în OpenAPI 3.1 este verificată cu fiecare fișier înainte de publicare.
  • /data nu este API-ul. Fișierele din /data/ sunt ceea ce încarcă harta: forma lor se schimbă fără preaviz, iar cererile către ele pot fi limitate. Construiți pe /api/v1/.
  • Fotografiile își păstrează propriile licențe, indicate pe pagina fiecărui loc și pe pagina surselor.

Începeți

const api = "{{site}}/api/v1";
const places = await (await fetch(`${api}/places.json`)).json();
const byId = new Map(places.map((p) => [p.id, p]));
const acts = await (await fetch(`${api}/verses/Acts.json`)).json();
for (const id of acts["Acts.16.12"]) console.log(byId.get(id).name); // Philippi …

Fișierele și câmpurile lor: Date deschise. Descrierea pentru generatoare de cod și agenți: openapi.json.
