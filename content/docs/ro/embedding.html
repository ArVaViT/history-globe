--- title: Încorporare description: Puneți globul pe propriul site cu un singur rând — harta unui capitol, a unui loc, a unui an sau a unui traseu — și controlați-l din pagina dumneavoastră. ---

Globul rulează în orice pagină ca iframe. Un singur rând arată harta unui capitol lângă pasajul din pagina dumneavoastră; câteva mesaje le sincronizează pe cele două.

Pornire rapidă

<iframe
  src="{{site}}/embed/v1?ref=Acts.16&locale=ro"
  title="Harta: Fapte 16"
  style="width: 100%; height: 480px; border: 0; border-radius: 12px"
  allow="fullscreen"
  loading="lazy"
></iframe>
  • Harta umple cadrul și se deschide pe locurile din Fapte 16, în anul evenimentelor lui.
  • Sus: capitolul. Selectați-l ca să-i vedeți locurile în ordinea în care le numește textul; selectați un loc ca să-i deschideți fișa.
  • Jos: anul. Selectați-l ca să deschideți cursorul de timp.
  • Un link deschide aceeași vedere în globul complet, într-o filă nouă. Mențiunile surselor sunt afișate chiar pe hartă, așa cum cer licențele datelor.
  • Cadrul funcționează până la lățimea unui telefon; o înălțime de 480 px este suficientă.

Un capitol sau un pasaj

ref primește o trimitere OSIS, cu abrevierile englezești ale cărților și numerotarea englezească a versetelor:

Valoare Arată
Acts.16 un capitol
Gen.12-Gen.13 până la trei capitole
Acts.16.11-Acts.16.15 un pasaj
Ruth o carte întreagă

Harta trece la anul pasajului: anul înregistrat al capitolelor sale (capitolele din {{chapter_books}} de cărți sunt datate) sau, altfel, anul traseului care îl acoperă; o carte întreagă ia anul traseului cu cele mai multe opriri în ea. Un pasaj fără niciuna dintre acestea păstrează anul curent al hărții.

Parametri

Parametru Exemplu Semnificație
ref Acts.16 capitol, pasaj sau carte (mai sus)
year -999 anul, în numerotare astronomică: 1 î.Hr. este 0, 1000 î.Hr. este -999
place af2161c deschide un loc (aici, Capernaum); ID-urile sunt cele ale OpenBible
tour paul-1 pornește un traseu ghidat
stop 3 cu tour: îl deschide la acea oprire
lesson a15257a~30.a112427~30 propria lecție, cu tour=lesson: ID-urile locurilor în ordine, fiecare cu anul în care să fie arătat (~-585 pentru 586 î.Hr.: ca la year, 1 î.Hr. este 0); fiecare oprire primește versetul locului cel mai apropiat de acel an, distanța, timpul de mers pe jos și relieful. Butonul „Adaugă la o lecție” de pe fișa unui loc construiește aceleași linkuri
title Paul%20in%20Galatia cu lesson: numele lecției, de până la 80 de caractere, în capul traseului ei și al foii ei tipărite
locale en limba: en, ru, uk, es, pt, de, fr, it, nl, pl, cs sau ro
camera 35.2,31.8,7,30,0 longitudine, latitudine, zoom, înclinare, orientare
hide relief,ancient straturile de ascuns: borders, places, relief, routes, roads, ancient

Cel mai simplu mod de a construi o vedere este să o pregătiți în globul complet și să copiați adresa URL: aceiași parametri funcționează după /embed/v1.

Mesaje

Globul și pagina dumneavoastră comunică prin postMessage. Fiecare mesaj este un obiect cu type și v: 1. Globul trimite doar ce se întâmplă pe hartă și niciodată ceva care să-l identifice pe cititor; acceptă mesaje doar de la pagina care conține cadrul.

De la glob

Tip Conținut Când
hg:ready { view } harta a fost desenată
hg:view-changed { view } anul, locul, traseul sau camera s-au schimbat și s-au stabilizat
hg:verse-clicked { osis } cititorul a dat clic pe un verset, de exemplu "Acts.16.12"
hg:error { code, message } harta sau datele ei nu s-au putut încărca

view conține year, locale și layers și, când sunt setate, place, tour, stop, ref și camera.

Către glob

Tip Conținut Efect
hg:set-view { view } setează anul, capitolul (ref), locul, straturile sau camera; cu tour (și stop), traseul pornește, iar celelalte câmpuri sunt ignorate; limba se schimbă doar cu hg:set-locale
hg:set-locale { locale } schimbă limba

Exemplu: harta urmează cititorul dumneavoastră

const globe = document.querySelector("iframe").contentWindow;

// Când cititorul dumneavoastră deschide un capitol, arătați-l pe hartă.
function showChapter(osis) {
  globe.postMessage({ type: "hg:set-view", v: 1, view: { ref: osis } }, "*");
}

// Când se dă clic pe un verset pe hartă, deschideți-l în cititorul dumneavoastră.
window.addEventListener("message", (e) => {
  if (e.source !== globe) return;
  if (e.data?.type === "hg:verse-clicked") openVerse(e.data.osis);
});

Locuri în orice text

Încă un rând leagă de glob locurile biblice pe care le numește propriul dumneavoastră text (un articol, o predică, un plan de lectură). Indicați un nume cu mouse-ul sau atingeți-l pe telefon și o fișă arată ce este locul, unde se află astăzi, câte versete îl numesc și unde se găsește pe hartă; fișa duce la glob. 

<script src="{{hgPlacesSrc}}" integrity="{{hgPlacesIntegrity}}" crossorigin="anonymous" data-scope="article" charset="utf-8" defer></script>

Adresa conține o versiune, iar hash-ul de integritate îi fixează conținutul exact: browserul rulează scriptul doar dacă este exact acel fișier. O versiune nouă primește o adresă nouă; cele vechi rămân așa cum sunt.

Atribut Ce face
data-scope unde să caute, ca selector CSS; implicit, toată pagina
data-locale limba textului, una dintre limbile site-ului: cs, de, en, es, fr, it, nl, pl, pt, ro, ru, uk; implicit, atributul lang al paginii; orice altă limbă revine la engleză
data-every leagă fiecare mențiune, nu doar prima a fiecărui loc
data-theme light sau dark pentru fișă; implicit, urmează sistemul cititorului

Sunt legate doar numele care indică un singur loc. Un nume comun pentru două locuri (Antiohia, cea din Siria și cea din Pisidia), pentru un loc și o persoană (Iuda) sau pentru un loc și un cuvânt obișnuit rămâne text simplu, la fel ca un nume pe care versetele Bibliei înseși îl folosesc mai ales pentru altceva („Cades” acolo este Cades-Barnea, nu Cadesul din baza de date). Numele unui loc care este și prenume (Jordan, Sharon) este lăsat neatins lângă un alt cuvânt cu majusculă: Jordan Smith este o persoană, nu râul. În rusă, ucraineană, poloneză și cehă, numele sunt găsite și în formele lor flexionate („в Египте”, „w Jerozolimie”, „v Jeruzalémě”), iar numele germane și la genitiv („Jerusalems”). Linkurile, codul, câmpurile de formular, butoanele și titlurile sunt lăsate neatinse.

Scriptul nu are dependențe și nu setează cookie-uri. Citește de pe glob un singur fișier de nume (aproximativ 20–35 KB transferați, în funcție de limbă, plus 7 KB de script), fără adresa paginii dumneavoastră ca referrer, și modifică doar numele pe care le leagă. Funcționează sub o politică Content Security Policy strictă care permite adresa globului în script-src și connect-src. Pentru textul pe care pagina îl adaugă mai târziu, apelați HistoryGlobePlaces.scan(element) după ce textul a fost afișat: scriptul împarte nodurile de text, așa că într-o pagină React sau Vue rulați-l pe conținut pe care framework-ul nu îl mai redesenează.

Stabilitate

/embed/v1 este un contract: în cadrul v1, parametrii și mesajele doar se adaugă, nu sunt niciodată schimbate sau eliminate. O schimbare incompatibilă va apărea ca /embed/v2, iar v1 va continua să funcționeze.
