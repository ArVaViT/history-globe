Tot ce știe globul despre locuri și versete este deschis: fișiere JSON simple, libere de folosit pe alt site sau în altă aplicație sub CC BY 4.0. Fără cheie, fără înregistrare, fără alte limite decât cache-ul obișnuit.

Ce locuri numește un verset

Câte un fișier pentru fiecare carte a Bibliei: fiecare verset care numește un loc, cu ID-urile acelor locuri. 

GET {{site}}/api/v1/verses/Acts.json

{ "Acts.16.11": ["a6a7150", "a68750d", "a91c509"], "Acts.16.12": ["a69e1b8", "a49e1d0"], … }

Locurile însele, cu numele lor în fiecare limbă a site-ului, tipul și punctul, se află în places.json; uniți-le după id. Câmpul name_ru din prima versiune este încă acolo, identic cu names.ru. 

GET {{site}}/api/v1/places.json

[{ "id": "a49e1d0", "name": "Philippi",
   "names": { "cs": "Filipy", "de": "Philippi", "es": "Filipos", …, "ru": "Филиппы", "uk": "Філіппи" },
   "kind": "settlement", "lon": 24.28458, "lat": 41.01207, "verses": 4,
   "wikidata": "Q379652", "pleiades": "501482",
   "page": { "cs": "/cs/place/philippi/", "de": "/de/place/philippi/", …, "uk": "/uk/place/philippi/" } }, …]

Cine și unde într-un capitol

Câte un fișier pentru fiecare carte: fiecare capitol, cu locurile și persoanele pe care le numește. Persoanele sunt identificate ca în TIPNR de la STEPBible; numele lor și primul verset se află în people.json. 

GET {{site}}/api/v1/chapters/Acts.json

{ "Acts.16": { "places": ["a6a7150", "a49e1d0", …],
               "people": ["Lydia@Act.16.14-", "Paul@Act.7.58-2Pe", "Silas@Act.15.22-1Pe", …] }, … }

Toate fișierele

Fișier Ce conține
/api/v1/index.json lista fișierelor și a cărților, licența și mențiunile surselor, data build-ului
/api/v1/places.json fiecare loc: ID, nume, tip, punct, câte versete îl numesc, pagina lui (pentru un loc pe care îl numește vreun verset); wikidata și pleiades, același loc în acele repertorii geografice, acolo unde este cunoscut
/api/v1/verses/{Book}.json un verset → locurile pe care le numește, câte un fișier pentru fiecare carte (Gen, 1Kgs, Acts…)
/api/v1/chapters/{Book}.json un capitol → locurile și persoanele pe care le numește, câte un fișier pentru fiecare carte
/api/v1/people.json persoanele pe care le numește Biblia: ID-ul TIPNR, numele, numele în celelalte limbi acolo unde site-ul le are, sexul, câte versete le numesc, primul dintre ele
/api/v1/events.json evenimentele datate, cu ref acolo unde Biblia relatează evenimentul
/api/v1/battles.json bătăliile și asediile: locul, anul, taberele și deznodământul, cu ref acolo unde Biblia relatează bătălia
/api/v1/questions.json întrebări pe care le pun oamenii, cu răspunsuri în fiecare limbă a site-ului, cu vederea hărții și sursele
/api/v1/tours.json traseele: opririle lor în ordine, fiecare cu pasajul și nota sa; by: "sea" pentru o porțiune parcursă pe mare și sailed (zilele și versetul) acolo unde textul spune cât a durat
/api/v1/ancient.json ce spun despre un loc autorii din afara Bibliei: autorul, opera, pasajul, un link către un text disponibil gratuit, un rezumat
/api/v1/openapi.json toate acestea descrise în OpenAPI 3.1, pentru generatoare de cod și agenți

Convenții

  • Trimiterile sunt în format OSIS, cu abrevierile englezești ale cărților și numerotarea King James: Gen.12.6, Acts.16.12-Acts.16.15.
  • Anii sunt astronomici: 1 î.Hr. este 0, 586 î.Hr. este −585.
  • Un loc înregistrat de două ori sub același nume în datele-sursă are "duplicate": true; un loc al cărui sit este disputat, "disputed": true.
  • Fișierele sunt reconstruite la fiecare lansare a datelor; index.json îi dă data.
  • Versiunea 1 doar crește: câmpurile și fișierele se adaugă, nu sunt niciodată redenumite sau eliminate. Ignorați un câmp pe care nu îl cunoașteți.
