Всё, что глобус знает о местах, стихах, людях и путешествиях, можно брать и строить на этом своё — через открытые данные и встраивание. Сам глобус, его статьи и код копировать нельзя. Эта страница — о том, где проходит граница.

Что можно брать

Что Лицензия Как
Данные: места с названиями на всех языках, точки, стихи и главы, где они названы, люди, экскурсии, события, битвы, античные авторы CC BY 4.0 {{site}}/api/v1/ — JSON-файлы, без ключа и регистрации. Используйте, изменяйте, продавайте то, что на них построили; сохраняйте указание источника.
Карта на вашей странице бесплатно Один iframe: Встраивание. Источники указаны на самой карте.
Ссылки и карточки для библейских мест, названных в ваших текстах бесплатно Один скрипт: Места в любом тексте.
Статьи о местах и ответы на вопросы, на всех языках CC BY-NC-ND 4.0 Цитируйте, ссылайтесь, делитесь ими как есть, с указанием источника. Не изменяйте, не переводите, не публикуйте заново и не включайте в наборы данных.
Сайт, его код и дизайн все права защищены Открытый для чтения код на GitHub не даёт права им пользоваться. Никаких зеркал, копий глобуса и сайтов, собранных из его бандла или файлов /data.

Коротко: данные берите через API и указывайте источник; карту показывайте через встраивание; глобус не клонируйте.

Как указать источник

Там, где вы показываете данные, назовите их источники так, как перечисляет index.json. Самая короткая форма, достаточная для лицензий: 

Данные: History Globe, Vadym Arnaut ({{site}}), CC BY 4.0;
места и привязки стихов — OpenBible.info (CC BY 4.0); люди — STEPBible TIPNR (CC BY 4.0).

На странице, со ссылками:

<p>Данные: <a href="{{site}}/">History Globe</a>, Vadym Arnaut,
  <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>;
  места — <a href="https://www.openbible.info/geo/">OpenBible.info</a>,
  люди — <a href="https://www.stepbible.org/">STEPBible</a>.</p>

Полные строки указания источников — в {{site}}/api/v1/index.json, и каждый ответ API приходит с заголовком Link, называющим его лицензию. Процитированную статью или ответ подписывают «History Globe (Vadym Arnaut), CC BY-NC-ND 4.0» со ссылкой на её страницу.

Ограничения

  • Без ключа и без квоты. API — это статические файлы за кэшем. Забирайте каждый файл при сборке или раз в день: они меняются только с выпуском, а index.json даёт его дату.
  • Версия 1 только растёт. Поля и файлы добавляются, но не переименовываются и не удаляются; незнакомое поле просто пропускайте. Описание в OpenAPI 3.1 сверяется с каждым файлом перед публикацией.
  • /data — не API. Файлы в /data/ загружает сама карта: их форма меняется без предупреждения, а запросы к ним могут ограничиваться по частоте. Стройте на /api/v1/.
  • Фотографии остаются под своими лицензиями, указанными на странице каждого места и на странице источников.

С чего начать

const api = "{{site}}/api/v1";
const places = await (await fetch(`${api}/places.json`)).json();
const byId = new Map(places.map((p) => [p.id, p]));
const acts = await (await fetch(`${api}/verses/Acts.json`)).json();
for (const id of acts["Acts.16.12"]) console.log(byId.get(id).name); // Philippi …

Файлы и их поля: Открытые данные. Описание для генераторов кода и агентов: openapi.json.

Если нужно больше

Перевод статей, их текст на другой платформе или лицензия, которой нет в таблице выше, — пишите на historyglobe.vadym@gmail.com. Партнёры получают письменную лицензию на то, что им нужно; публичные лицензии остаются как есть.
