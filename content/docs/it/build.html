Tutto ciò che il globo sa di luoghi, versetti, persone e itinerari è a tua disposizione per costruirci sopra, tramite i dati aperti e l’incorporamento. Il globo stesso, i suoi articoli e il suo codice non sono da copiare. Questa pagina dice dove passa il confine.

In breve: prendi i dati tramite l’API e cita la fonte; mostra la mappa tramite l’incorporamento; non clonare il globo.

Come citare la fonte

Dove mostri i dati, nomina le loro fonti come le elenca index.json. La forma più breve che soddisfa le licenze: 

Dati: History Globe di Vadym Arnaut ({{site}}), CC BY 4.0;
luoghi ed etichette dei versetti da OpenBible.info (CC BY 4.0); persone da STEPBible TIPNR (CC BY 4.0).

In una pagina, con i link:

<p>Dati: <a href="{{site}}/">History Globe</a> di Vadym Arnaut,
  <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>;
  luoghi da <a href="https://www.openbible.info/geo/">OpenBible.info</a>,
  persone da <a href="https://www.stepbible.org/">STEPBible</a>.</p>

{{site}}/api/v1/index.json contiene le righe complete dei crediti, e ogni risposta dell’API è inviata con un header Link che ne indica la licenza. Un articolo o una risposta citati vanno accreditati come «History Globe (Vadym Arnaut), CC BY-NC-ND 4.0», con un link alla loro pagina.

Limiti

  • Nessuna chiave, nessuna quota. L’API è fatta di file statici dietro una cache. Scarica ogni file quando costruisci o una volta al giorno: cambiano solo con un rilascio, e index.json ne indica la data.
  • La versione 1 non fa che crescere. Campi e file si aggiungono, senza mai essere rinominati o rimossi; ignora un campo che non conosci. La descrizione in OpenAPI 3.1 viene verificata su ogni file prima della pubblicazione.
  • /data non è l’API. I file sotto /data/ sono ciò che la mappa carica: la loro forma cambia senza preavviso, e le richieste verso di essi possono essere limitate. Costruisci su /api/v1/.
  • Le fotografie conservano le proprie licenze, indicate su ogni pagina di luogo e nella pagina delle fonti.

Per iniziare

const api = "{{site}}/api/v1";
const places = await (await fetch(`${api}/places.json`)).json();
const byId = new Map(places.map((p) => [p.id, p]));
const acts = await (await fetch(`${api}/verses/Acts.json`)).json();
for (const id of acts["Acts.16.12"]) console.log(byId.get(id).name); // Philippi …
