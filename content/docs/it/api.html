--- title: Dati aperti description: I luoghi, i versetti che li nominano, gli eventi e gli itinerari come file JSON che chiunque può usare sotto CC BY 4.0 — senza chiave, senza registrazione. ---

Tutto ciò che il globo sa dei luoghi e dei versetti è aperto: semplici file JSON, liberi da usare in un altro sito o app sotto CC BY 4.0. Nessuna chiave, nessuna registrazione, nessun limite oltre alla normale memorizzazione in cache.

Quali luoghi nomina un versetto

Un file per ogni libro della Bibbia: ogni versetto che nomina un luogo, con gli id di quei luoghi. 

GET {{site}}/api/v1/verses/Acts.json

{ "Acts.16.11": ["a6a7150", "a68750d", "a91c509"], "Acts.16.12": ["a69e1b8", "a49e1d0"], … }

I luoghi stessi, con i nomi in inglese e in russo, il tipo e il punto, sono in places.json; il collegamento avviene tramite id. 

GET {{site}}/api/v1/places.json

[{ "id": "a49e1d0", "name": "Philippi", "name_ru": "Филиппы", "kind": "settlement",
   "lon": 24.28458, "lat": 41.01207, "verses": 4,
   "page": { "en": "/en/place/philippi/", "ru": "/ru/place/philippi/" } }, …]

Tutti i file

File Che cosa contiene
/api/v1/index.json l’elenco dei file e dei libri, la licenza e i crediti, la data della build
/api/v1/places.json ogni luogo: id, nomi, tipo, punto, quanti versetti lo nominano, la sua pagina (per un luogo nominato da qualche versetto)
/api/v1/verses/{Book}.json un versetto → i luoghi che nomina, un file per libro (Gen, 1Kgs, Acts…)
/api/v1/events.json gli eventi datati, con ref dove la Bibbia racconta l’evento
/api/v1/battles.json battaglie e assedi: luogo, anno, schieramenti ed esito, con ref dove la Bibbia racconta la battaglia
/api/v1/questions.json le domande che le persone pongono, con risposta in entrambe le lingue, la vista della mappa e le fonti
/api/v1/tours.json gli itinerari: le loro tappe in ordine, ciascuna con il suo brano e la sua nota; by: "sea" per un tratto percorso per mare, e sailed (giorni e versetto) dove il testo dice quanto durò

Convenzioni

  • I riferimenti sono in OSIS con le abbreviazioni inglesi dei libri e la numerazione della King James: Gen.12.6, Acts.16.12-Acts.16.15.
  • Gli anni sono astronomici: l’1 a.C. è 0, il 586 a.C. è −585.
  • Un luogo elencato due volte con lo stesso nome nei dati di origine porta "duplicate": true; un luogo il cui sito è discusso, "disputed": true.
  • I file vengono ricostruiti a ogni rilascio dei dati; index.json ne indica la data.
