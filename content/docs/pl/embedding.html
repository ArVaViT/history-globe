--- title: Osadzanie description: Umieść globus na własnej stronie jedną linijką — mapę rozdziału, miejsca, roku lub trasy — i steruj nim ze swojej strony. ---

Globus działa na dowolnej stronie jako iframe. Jedna linijka pokazuje mapę rozdziału obok fragmentu tekstu na Twojej stronie, a kilka komunikatów utrzymuje oba w zgodzie.

Szybki start

<iframe
  src="{{site}}/embed/v1?ref=Acts.16&locale=pl"
  title="Mapa Dz 16"
  style="width: 100%; height: 480px; border: 0; border-radius: 12px"
  allow="fullscreen"
  loading="lazy"
></iframe>
  • Mapa wypełnia ramkę i otwiera się na miejscach z Dz 16, w roku opisanych tam wydarzeń.
  • U góry: rozdział. Wybierz go, aby zobaczyć jego miejsca w kolejności, w jakiej wymienia je tekst; wybierz miejsce, aby otworzyć jego kartę.
  • Na dole: rok. Wybierz go, aby otworzyć suwak czasu.
  • Link otwiera ten sam widok w pełnym globusie w nowej karcie. Informacje o autorach danych są pokazane na samej mapie, jak tego wymagają licencje.
  • Ramka działa nawet przy szerokości telefonu; wystarczy wysokość 480 px.

Rozdział lub fragment

ref przyjmuje odwołanie OSIS z angielskimi skrótami ksiąg i angielską numeracją wersetów:

Wartość Pokazuje
Acts.16 rozdział
Gen.12-Gen.13 do trzech rozdziałów
Acts.16.11-Acts.16.15 fragment
Ruth całą księgę

Mapa przesuwa się do roku fragmentu: zapisanego roku jego rozdziałów (datowane są rozdziały {{chapter_books}} ksiąg) albo, w braku tego, roku trasy, która go obejmuje; cała księga przyjmuje rok trasy, która ma w niej najwięcej przystanków. Fragment, który nie ma ani jednego, ani drugiego, zachowuje bieżący rok mapy.

Najłatwiej zbudować widok, ustawiając go w pełnym globusie i kopiując adres URL: te same parametry działają po /embed/v1.

Komunikaty

Globus i Twoja strona komunikują się przez postMessage. Każdy komunikat jest obiektem z polami type i v: 1. Globus wysyła tylko to, co dzieje się na mapie, i nigdy nic, co identyfikuje czytelnika, więc wysyła komunikaty do strony nadrzędnej bez względu na jej pochodzenie (cel "*"); przyjmuje komunikaty wyłącznie ze strony, która zawiera ramkę.

Z globusa

Typ Zawartość Kiedy
hg:ready { view } mapa jest narysowana
hg:view-changed { view } rok, miejsce, trasa lub kamera zmieniły się i ustabilizowały (około 400 ms po ostatniej zmianie), niezależnie od tego, czy zmienił je czytelnik, czy Twoje hg:set-view. Gdy mapa leci do nowo wybranego miejsca, komunikat przychodzi raz z nowym miejscem i kamerą, którą mapa opuściła, a potem jeszcze raz, gdy przelot się kończy
hg:place-clicked { place } czytelnik kliknął miejsce na mapie, także to już zaznaczone; komunikat przychodzi przed hg:view-changed, który wywołuje to kliknięcie
hg:verse-clicked { osis } czytelnik kliknął werset na karcie miejsca, np. "Acts.16.12"
hg:error { code, message } nie udało się wczytać mapy lub jej danych: code to "map" albo "data"

view zawiera year, locale i layers oraz, gdy są ustawione, place, tour, stop, ref i camera. view bez place oznacza, że żadne miejsce nie jest zaznaczone. camera to obiekt, { center: [35.2, 31.8], zoom: 7, pitch: 30, bearing: 0 }, a nie ciąg znaków z adresu; layers nadaje każdej warstwie true albo false: { relief: false, battles: false }.

Do globusa

Typ Zawartość Skutek
hg:set-view { view } ustawia rok, rozdział (ref), miejsce, warstwy lub kamerę; z tour (i stop) uruchamia się trasa, a pozostałe pola są ignorowane; język zmienia się tylko przez hg:set-locale. place: null usuwa zaznaczenie i kończy trwającą trasę. Do już zaznaczonego miejsca leci się ponownie, chyba że widok zawiera też camera. Identyfikator miejsca, którego mapa nie ma, jest ignorowany
hg:set-locale { locale } przełącza język
  • Zaczekaj na hg:ready, zanim cokolwiek wyślesz: komunikat wysłany, gdy mapa jeszcze się wczytuje, ginie.
  • Traktuj hg:view-changed jako stan bieżący, a nie coś, co zrobił czytelnik: następuje po Twoim hg:set-view i po każdym ruchu kamery. Strona, która odsyła cały widok taki, jaki dostała, razem z kamerą, nie zaczyna ani pętli, ani przelotu. Nie odpowiadaj na hg:view-changed przez hg:set-view z samym place: bez camera mapa leci z powrotem do tego miejsca, z dala od tego, gdzie przesunął ją czytelnik.

Identyfikatory miejsc

Miejsce biblijne ma identyfikator OpenBible: a i sześć cyfr szesnastkowych, na przykład af2161c (Kafarnaum). Miejsca świata starożytnego, których Biblia nie wymienia (Gamla, Sefforis, Pompeje), mają zamiast tego numer Pleiades (Gamla ma 678146), a bez niego element Wikidata (Konstantynopol ma Q16869). Oba rodzaje mogą pojawić się w view.place i hg:place-clicked, a hg:set-view przyjmuje oba; jeśli Twoje dane zawierają tylko miejsca OpenBible, sprawdź postać identyfikatora, zanim zaczniesz go wyszukiwać. Spośród {{openbible}} miejsc OpenBible {{absent}} nie ma na mapie (pominięte albo w ogóle bez punktu); ich identyfikatory są ignorowane.

Przykład: mapa podąża za czytelnikiem

const globe = document.querySelector("iframe").contentWindow;

// When your reader opens a chapter, show it on the map.
function showChapter(osis) {
  globe.postMessage({ type: "hg:set-view", v: 1, view: { ref: osis } }, "*");
}

// When a verse is clicked on the map, open it in your reader.
window.addEventListener("message", (e) => {
  if (e.source !== globe) return;
  if (e.data?.type === "hg:verse-clicked") openVerse(e.data.osis);
});

Przykład: mapa obok Twojego własnego pola miejsca

<iframe src="{{site}}/embed/v1?ui=map&place=af2161c&locale=en" title="Map"></iframe>
const globe = document.querySelector("iframe").contentWindow;
let ready = false;

window.addEventListener("message", (e) => {
  if (e.source !== globe) return;
  const m = e.data;
  if (m?.type === "hg:ready") ready = true;
  // Widok taki, jaki jest teraz: miejsce wybrane albo żadne. Przychodzi często: showPlace nie
  // powinno nic robić, gdy to miejsce jest już pokazane.
  if (m?.type === "hg:ready" || m?.type === "hg:view-changed") {
    if (m.view.place) showPlace(m.view.place);
    else hidePlace();
  }
  // Każde kliknięcie miejsca, także już wybranego: otwórz ponownie swoje pole.
  if (m?.type === "hg:place-clicked") showPlace(m.place);
});

// Twoja wyszukiwarka wybrała miejsce: wybierz je i leć do niego (ponownie, jeśli jest już wybrane).
function pickPlace(id) {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: id } }, "*");
}

// Twoje pole zostało zamknięte: usuń zaznaczenie na mapie.
function closeBox() {
  if (ready) globe.postMessage({ type: "hg:set-view", v: 1, view: { place: null } }, "*");
}
  • Wybrane miejsce jest oznaczone pierścieniem, który rośnie i blednie, dzięki czemu oko go znajduje, a nic nie zasłania mapy; dla czytelnika, który prosił o mniej ruchu, pierścień stoi nieruchomo.
  • Kliknięcie mapy z dala od jakiegokolwiek miejsca usuwa zaznaczenie miejsca; trwająca trasa toczy się dalej. Dwukliknięcie (które przybliża) i kliknięcie zatrzymujące poruszającą się mapę nie usuwają niczego. place: null z Twojej strony usuwa miejsce i kończy trasę.
  • Trasa działa na mapie (jej linia, jej przystanki i rok) bez swojej karty: Twoja strona steruje nią przez hg:set-view i { tour, stop }. measure rysuje swoją linię, jak w każdej ramce.
  • hg:verse-clicked nie jest wysyłany: wersety są na karcie miejsca, której ten tryb nie ma.

Miejsca w dowolnym tekście

Jeszcze jedna linijka wiąże z globusem miejsca biblijne, które wymienia Twój własny tekst (artykuł, kazanie, plan czytania). Wskaż nazwę albo dotknij jej na telefonie, a karta pokaże, czym jest to miejsce, gdzie leży dziś, ile wersetów je wymienia i gdzie znajduje się na mapie; karta prowadzi do globusa. 

<script src="{{hgPlacesSrc}}" integrity="{{hgPlacesIntegrity}}" crossorigin="anonymous" data-scope="article" charset="utf-8" defer></script>

Adres zawiera wersję, a skrót integralności utrwala jej dokładną zawartość: przeglądarka wykona skrypt tylko wtedy, gdy jest to dokładnie ten plik. Nowa wersja dostaje nowy adres; stare pozostają bez zmian.

Atrybut Co robi
data-scope gdzie szukać, jako selektor CSS; domyślnie cała strona
data-locale język tekstu, jeden z języków serwisu: {{locale_codes}}; domyślnie lang strony; dla innych języków angielski
data-every wiąże każdą wzmiankę, a nie tylko pierwszą dla każdego miejsca
data-theme light lub dark dla karty; domyślnie zgodnie z ustawieniem systemu czytelnika

Wiązane są tylko nazwy, które wskazują jedno miejsce. Nazwa wspólna dla dwóch miejsc (Antiochia syryjska i pizydyjska), dla miejsca i osoby (Juda) albo dla miejsca i zwykłego słowa pozostaje zwykłym tekstem, podobnie jak nazwa, której same wersety Biblii używają przeważnie w innym znaczeniu („Kadesz” oznacza tam Kadesz-Barnea, a nie Kadesz z bazy danych). Nazwa miejsca, która jest też imieniem (Jordan, Szaron), nie jest wiązana obok innego słowa pisanego wielką literą: Jordan Smith to osoba, a nie rzeka. W języku rosyjskim, ukraińskim, polskim, czeskim, serbskim, węgierskim, fińskim i rumuńskim nazwy są znajdowane w różnych przypadkach („в Египте”, „w Jerozolimie”, „v Jeruzalémě”), a w niemieckim, szwedzkim, duńskim i norweskim także w dopełniaczu („Jerusalems”). Linki, kod, pola formularzy, przyciski i nagłówki są pomijane.

Skrypt nie ma zależności i nie ustawia plików cookie. Czyta z globusa jeden plik nazw (od {{names_kb_min}} do {{names_kb_max}} KB przez sieć, zależnie od języka, plus {{script_kb}} KB samego skryptu), bez przekazywania adresu Twojej strony jako referera, i zmienia tylko te nazwy, które wiąże. Działa przy ścisłej polityce bezpieczeństwa treści (Content Security Policy), która zezwala na adres globusa w script-src i connect-src. Dla tekstu, który Twoja strona doda później, wywołaj HistoryGlobePlaces.scan(element), gdy tekst zostanie wyrenderowany: skrypt dzieli węzły tekstowe, więc na stronie React lub Vue uruchamiaj go na treści, której framework już nie renderuje ponownie.

Stabilność

/embed/v1 jest kontraktem: w ramach v1 parametry i komunikaty są tylko dodawane, nigdy zmieniane ani usuwane. Zmiana łamiąca zgodność ukaże się jako /embed/v2, a v1 nadal będzie działać.
