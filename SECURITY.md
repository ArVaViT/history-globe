# Security

Report a security problem in historyglobe.app or in this repository privately, by email to
historyglobe.vadym@gmail.com. Please do not open a public issue for it.

Say what you found, where, and how to reproduce it. You will get a reply, and a confirmed
problem is fixed as soon as it can be. The site is static files with no accounts and no
server of its own, so there is no user data to expose; reports about the build, the headers,
the deployed files or the repository are all welcome.

The same contact is published at https://historyglobe.app/.well-known/security.txt.
